# 说给 Claude 听（语音对话页面）

一个在 claude.ai 上打开的网页，用来跟 Claude 语音对话：用系统听写说话，Claude 的回答一边生成一边朗读出来。

在线地址：https://claude.ai/artifact/DpxVuvDrVVUTUZNrPtKs7T （目前只有本人能打开；要给别人用，在页面的“分享”菜单里设置）

## 怎么用

1. 打开上面的链接（手机上可在 Claude 应用或浏览器里打开）。
2. 轻点输入框，按系统的听写键说话：
   - 手机：键盘上的麦克风键；
   - Mac：按两下 Fn 键（需先在“系统设置 → 键盘 → 听写”里打开）；
   - Windows：按 Win + H。
3. 说完停顿一下（默认 3 秒），就会自动发送。第一次发送时，页面会请你允许它使用 Claude。
4. 回答会被朗读出来。你一开口说话，朗读就停下；“停止”键可以同时停下生成和朗读。

## 设置

- 朗读开关、语速、中文声音（英文句子自动换英文声音）；
- 停顿后自动发送，以及停顿多久算说完（2 / 3 / 5 秒）；
- 回答长短（简短 / 适中 / 详细）；
- 深入思考：回答更周到，但要多等一会儿；
- 清空对话。对话记录只保存在当前设备的浏览器里。

## 已知限制

- 页面本身不能直接调用麦克风，所以语音输入靠系统听写，而不是网页录音。
- 朗读用的是设备自带的语音合成，音色取决于系统里装了哪些声音。
- 每次调用都使用打开页面的人自己的 Claude 用量。

## 修改与重新发布

源文件是 `voice-chat.html`。改完后让 Claude 在会话里用 Artifact 工具重新发布到同一个地址即可。
