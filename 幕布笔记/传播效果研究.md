# 传播效果研究

- 【框架说明】（可删）
  - 结构：总览 → 四个阶段 → 跨分支联系 → 参考书目 → 预留分支
  - 每个阶段统一用七个模块展开：1、概念　2、产生背景　3、代表研究与人物　4、评价　5、向下一阶段过渡　6、考点与易错点　7、延伸与笔记
  - 符号：★ 重点、常考；→ 与其他分支的联系；【待补充】预留位置

- 一、总览：效果研究的发展脉络
  - 传播效果的两层含义
    - 狭义：带有说服动机的传播行为，在受众身上引起的心理、态度和行为变化
    - 广义：传播活动（尤其是大众传播）对受众和社会产生的一切影响和结果的总和
  - 效果的三个层面：认知（知道了什么）→ 心理和态度（怎么看）→ 行动（怎么做），逐层加深
  - 四个阶段（分期说法不一，时间为大致范围，前后有交叉）
    - 第一阶段：强效果论，即魔弹论｜20世纪初—30年代末
    - 第二阶段：有限效果论｜20世纪40—60年代
    - 第三阶段：适度效果论｜20世纪60年代末—70年代
    - 第四阶段：强效果论的回归｜20世纪70年代以后
  - 主线：对“媒介力量有多大”“受众是否主动”的判断不断被修正：从“媒介万能”，到“效果有限”，再到“在一定条件下效果强大”
  - 关注点的变化
    - 从“媒介对人做了什么”，扩展到“人用媒介做了什么”（使用与满足）
    - 从短期的态度、行为改变，扩展到长期、宏观的社会影响（议程设置、培养理论、知沟）
- 二、第一阶段：魔弹论阶段（强效果论）｜20世纪初—30年代末
  - 1、概念
    - 别称：魔弹论 / 子弹论 / 皮下注射论 / 刺激—反应论（S-R）★
    - 核心观点：大众传媒具有不可抗拒的强大力量。它传递的信息像子弹击中身体、药液注入皮下一样，能在受众身上引起直接、迅速的反应，能左右人们的态度和意见，甚至支配人们的行动
    - 受众观：受众是被动、孤立、彼此相似的“靶子”，只能接受，几乎无力抵抗
    - 传播观：单向、线性、直接。传者发出刺激，受众做出同样的反应
    - ★ 注意：当时并没有人正式提出一个叫“魔弹论”的理论。这个名称主要是后来的研究者（如施拉姆、德弗勒）对当时流行看法的概括；也有学者认为，它在一定程度上是后人树起来供批评的“靶子”
  - 2、产生背景
    - （1）社会背景：大众社会
      - 工业化、城市化使大量人口涌入城市，家庭、邻里、宗族等传统纽带变弱
      - 个人变得孤立、匿名、彼此疏离，缺少群体的保护和缓冲，因此被认为容易受到媒介的直接影响
      - “大众”（mass）★：规模庞大、分散、匿名、成员背景各异、缺乏组织、彼此很少互动（布鲁默的界定）
      - 思想来源：滕尼斯“共同体与社会”（1887）；涂尔干“机械团结与有机团结”（1893）；勒庞《乌合之众》（1895）
    - （2）媒介背景：新媒介兴起
      - 报纸：19世纪30年代出现“便士报”（如1833年的《纽约太阳报》），报纸走向大众；到20世纪初，发行量巨大的大众报刊已很普遍
      - 电影：1895年卢米埃尔兄弟首次公开放映；20世纪20年代好莱坞兴盛，1927年出现有声片《爵士歌王》，看电影成为大众的日常娱乐
      - 广播：1920年美国KDKA电台开播；20世纪30年代进入广播的“黄金时代”，罗斯福从1933年起的“炉边谈话”显示了广播直接面向全国听众说话的能力
      - 共同特点：覆盖面空前广、速度快、能同时触达大量分散的人，让人直观地感到媒介的“威力”
    - （3）政治经济背景
      - 战争宣传：一战中各国第一次大规模、有组织地开展宣传动员（如美国1917年成立的“公共信息委员会”，即克里尔委员会）。战后人们对宣传的威力既惊叹又恐惧
      - 极权主义：纳粹德国1933年设立“国民教育与宣传部”（戈培尔任部长），推广廉价的“国民收音机”，并用电影（如1935年的《意志的胜利》）做政治宣传。宣传被看作操纵民众的利器
      - 商业：广告业和公共关系业兴起。伯内斯在《舆论的结晶》（1923）、《宣传》（1928）中主张可以有计划地引导公众
      - 经济危机：1929年大萧条之后社会普遍焦虑，进一步加深了人们对媒介操纵力的担忧
    - （4）理论资源
      - 行为主义心理学（核心）★：华生（1913）主张心理学只研究可观察的行为，行为可以用“刺激—反应”（S-R）来解释；巴甫洛夫的条件反射实验也提供了支持 → 传播被看作“刺激”，受众的变化被看作“反应”
      - 本能心理学：麦独孤《社会心理学导论》（1908）认为人的行为由与生俱来的本能支配，而人人本能相同 → 同样的刺激会引起大致相同的反应
      - 大众社会理论与群体心理学：个人孤立无援；人在群体中容易失去理性（勒庞）→ 受众容易被操纵
  - 3、代表研究与人物（按时间排列）
    - ① 李普曼《舆论》（1922，又译《公众舆论》）：拟态环境 ★
      - 人物：沃尔特·李普曼，美国专栏作家、政论家，一战期间参与过宣传工作
      - 拟态环境（pseudo-environment）：大众传媒对事件和信息进行选择、加工、重新组织之后，向人们展示的环境。它不是客观环境“镜子式”的再现
      - 人们根据“头脑中的图景”而不是客观现实来行动，但这些行动又会作用于现实环境
      - 刻板成见（stereotype）：人们对某类人或事物形成的简单、固定的看法，会影响对新信息的理解
      - “制造同意”（manufacture of consent）：舆论可以被有意识地塑造
      - 与魔弹论的关系：强调媒介能塑造人们对世界的认识，反映了这一时期对媒介力量的重视
      - → 联系：议程设置理论（麦库姆斯和肖把李普曼视为思想先驱）；培养理论；“拟态环境的环境化”（藤竹晓）
    - ② 拉斯韦尔《世界大战中的宣传技巧》（1927）
      - 人物：哈罗德·拉斯韦尔，美国政治学家，传播学“四大奠基人”之一。本书在他的博士论文基础上写成
      - 内容：系统分析一战中英、法、德、美等国的宣传策略和手法，是最早的系统性宣传研究之一
      - 战时宣传的四个目标：激起对敌人的仇恨；维持与盟国的友谊；维持与中立国的友好关系，并尽量争取其合作；瓦解敌人的士气
      - 常用手法：把战争罪责归于敌方；渲染敌方的暴行；阐明正义的战争目的；宣扬必胜的信念
      - 宣传的定义：用有意义的符号（故事、谣言、报道、图片等）来控制意见
      - 结论：宣传是现代社会最有力的工具之一
      - 与魔弹论的关系：为“宣传威力巨大”的看法提供了系统的论证
      - → 联系：拉斯韦尔1948年的《社会传播的结构与功能》提出“5W模式”和传播的三种社会功能（归入“传播过程与模式”分支）
    - ③ 佩恩基金研究（1929—1932年开展，1933年起陆续出版）★
      - 组织：美国“电影研究委员会”在佩恩基金会资助下开展，由查特斯主持，邀请多所大学的心理学家、社会学家和教育学者参加
      - 问题：电影对青少年和儿童有什么影响
      - 方法：问卷、实验、内容分析、生理测量、自传与访谈等，是最早的大规模、系统的媒介效果实证研究之一
      - 主要发现
        - 信息：儿童能从电影中记住大量细节
        - 态度：电影能改变儿童对某些种族和民族的态度（如看过《一个国家的诞生》后，对黑人的态度变得更负面），部分变化几个月后仍然存在
        - 行为：青少年会模仿电影中的衣着、举止和恋爱方式（布鲁默《电影与行为》）
        - 情绪与生理：电影会引起强烈的情绪反应，还会影响睡眠
      - 结论：电影会改变青少年和儿童对衣着、举止乃至某一族裔的看法，并且效果持久
      - 社会影响：通俗读物《我们被电影塑造的孩子》（福尔曼，1933）夸大了研究结论，加剧了社会对电影的担忧，被认为推动了好莱坞1934年起严格执行内容审查（《海斯法典》）
      - ★ 注意：研究同时发现，效果因年龄、性别、家庭环境、已有经验等而不同 → 已经显露出“有限效果”的苗头
    - ④ “火星人入侵”事件与坎特里尔的研究（1938年事件，1940年出书）★
      - 事件：1938年10月30日（万圣节前夜），美国哥伦比亚广播公司（CBS）播出奥森·威尔斯根据H. G. 威尔斯小说《世界大战》改编的广播剧，用“新闻插播”的形式“报道”火星人在新泽西州登陆、入侵地球
      - 反应：据坎特里尔估计，约600万人收听，约170万人信以为真，约120万人受到惊吓，有人逃离家园、打电话求救
      - 研究：普林斯顿大学广播研究项目的哈德利·坎特里尔，与赫塔·赫佐格、黑兹尔·高德特一起展开研究，深入访谈了135名听众，并结合调查数据，1940年出版《火星人入侵：恐慌心理研究》
      - 听众的四种类型
        - 根据节目本身的线索，判断出是广播剧
        - 通过其他途径（换台、查报纸、打电话）核实后，判断出是广播剧
        - 试图核实，但仍然相信是真的
        - 根本没有核实，直接相信
      - 影响反应的因素
        - 批判能力：最重要的因素，与受教育程度有关
        - 个人心理特征：情绪不安、容易恐惧、缺乏自信、宿命论倾向、宗教虔诚
        - 收听情境：中途收听、错过了开头的声明；被他人告知，或和受惊的人在一起
        - 社会环境：大萧条和欧洲战争阴影下的普遍焦虑（1938年慕尼黑危机前后，人们已习惯从广播里听到紧急新闻）
      - ★ 注意：事件本身常被当作魔弹论的例证，但研究结论恰恰说明受众的反应因人而异 → 动摇了魔弹论，是向有限效果论过渡的标志性研究之一
      - 后人的反思：也有研究者认为，当时报纸夸大了“大恐慌”的规模（部分出于和新兴广播竞争的心理）
      - → 联系：赫佐格后来对广播肥皂剧听众的研究（1944）是“使用与满足”研究的先驱

  - 4、评价
    - 贡献
      - 第一次明确提出“媒介有什么效果”这个问题，开启了效果研究
      - 提醒人们警惕宣传和媒介操纵
      - 留下“拟态环境”“刻板成见”等影响深远的概念；佩恩基金研究等推动了实证方法在传播研究中的应用
    - 局限 ★
      - 夸大了媒介的力量，忽视了受众的主动性
      - 忽视了个体差异（心理、教育、需求等）和社会关系（家庭、群体、意见领袖）的作用
      - 把复杂的传播过程简化为单向、线性的“刺激—反应”
      - 多凭印象、个案和推测，缺少系统的实证检验
  - 5、向下一阶段过渡
    - 本阶段内部的“反证”：佩恩基金研究和“火星人入侵”研究都发现了个体差异
    - 1940年拉扎斯菲尔德等人开展伊里县研究（《人民的选择》，1944），发现媒介很少直接改变选民的投票意向，人际影响和“意见领袖”更重要 → 进入有限效果论阶段
  - 6、考点与易错点 ★
    - 名词解释｜魔弹论：20世纪初至30年代末流行的一种媒介效果观，又称“子弹论”“皮下注射论”。它认为大众传媒具有不可抗拒的强大力量，传递的信息像子弹击中身体、药液注入皮下一样，能在受众身上引起直接、迅速的反应。其理论基础是行为主义心理学的“刺激—反应”模式和大众社会理论。它夸大了媒介的力量，忽视了受众的主动性和社会因素的制约，后来被有限效果论取代
    - 名词解释｜拟态环境：李普曼在《舆论》（1922）中提出，指大众传媒对事件和信息进行选择、加工、重新组织之后向人们展示的环境。它不是客观环境“镜子式”的再现，但人们往往根据它来认识世界、采取行动，这些行动又会作用于现实环境
    - 易混：拉斯韦尔的两部著作。1927年《世界大战中的宣传技巧》是宣传研究；1948年《社会传播的结构与功能》提出5W模式和三功能
    - 易混：李普曼的两部著作。《舆论》（1922）提出拟态环境；《幻影公众》（1925）质疑普通公众参与公共事务的能力
    - 易混：两次“强效果”。第一次是魔弹论；第二次是20世纪70年代诺埃尔-诺依曼主张“回归大众传播的强大效果观”，提出沉默的螺旋
    - 易错：坎特里尔对“火星人入侵”的研究结论并不支持魔弹论
    - 易错：“魔弹论”不是某位学者正式提出的理论
  - 7、延伸与笔记
    - 思考题：社交媒体和算法推荐时代，魔弹论会不会以新的形式回来？可从谣言的快速扩散、信息茧房、深度伪造等现象谈起，同时要看到受众的选择、核实和反驳能力

- 三、第二阶段：有限效果论阶段｜20世纪40—60年代
  - 1、概念
    - 别称：有限效果论 / 最小效果论
    - 核心观点：大众传播通常不是产生效果的必要和充分条件，而是通过一系列中介因素起作用。它的主要效果是强化受众原有的态度，很少能改变态度
    - 受众观：受众不是孤立、被动的“靶子”，而是生活在家庭、群体等社会关系中，带着既有倾向、会有选择地接触信息的人
    - 中介因素 ★：既有倾向与选择性接触（以及选择性理解、选择性记忆）；所属群体及群体规范；人际传播；意见领袖；媒介的商业性质
    - 和魔弹论的对比 ★
      - 媒介力量：不可抗拒 → 有限，主要起强化作用
      - 受众：被动、孤立、相似 → 处在社会关系中、有既有倾向、会选择
      - 传播过程：直接、单向 → 经过中介因素，有人际传播参与
      - 研究方法：印象、个案、推测 → 大规模抽样调查、固定样本追踪、控制实验
    - ★ 注意：有限效果论不是说媒介“没有效果”，而是说效果受到中介因素的制约，主要表现为强化
  - 2、产生背景
    - （1）研究方法成熟：抽样调查、固定样本追踪调查（panel study）、控制实验和统计分析发展起来，效果研究走向实证化
    - （2）研究机构与资助
      - 普林斯顿广播研究项目（1937年成立，洛克菲勒基金会资助）1939年迁到哥伦比亚大学，后来发展为应用社会研究局，由拉扎斯菲尔德领导
      - 二战期间美国陆军部设立研究机构，霍夫兰等心理学家研究宣传影片对士兵的影响；战后转到耶鲁大学继续研究
    - （3）现实需求：总统选举中的竞选宣传、战时动员与士气、广播收听率和广告效果等商业需要
    - （4）理论资源
      - 心理学：重视个体差异，在“刺激”和“反应”之间加入受众自身的因素（S-O-R）
      - 社会学：重新发现了初级群体和人际关系的作用
      - 德弗勒后来把这些思路概括为三种理论：个人差异论、社会分类论、社会关系论
  - 3、代表研究与人物
    - ① 伊里县研究（1940年调查；《人民的选择》，1944）★
      - 人物：拉扎斯菲尔德、贝雷尔森、高德特
      - 背景：1940年美国总统选举（罗斯福对威尔基），地点是俄亥俄州伊里县
      - 目的：研究者原本预期，大众传媒的竞选宣传会对选民的投票决定产生很大影响
      - 方法：固定样本追踪调查（panel study）
        - 1940年5月，每四户抽一户，访问了约3000名居民
        - 从中抽出4组，每组600人，各组构成相近
        - 1组为主样本组：从5月到11月每月访问一次，共访问7次
        - 另外3组为对照组：分别在7月、8月、10月只再访问一次
        - 设对照组的目的：检验长期反复访问这一行为本身会不会影响投票选择。如果有影响，主样本组和对照组的结果会差别很大。结果两者没有明显差别，说明数据有效
      - 主要发现
        - 政治既有倾向 ★：社会经济地位、宗教信仰、居住地（城市或农村）大体决定了人们投谁的票。“一个人在政治上怎么想，取决于他在社会上是什么样的人”
        - 三种效果 ★：大众传媒的宣传主要是强化选民既有的投票意向，其次是激活潜在的倾向；真正因宣传而改变投票意向并最终付诸行动的选民比例很小（常被引用的数字是约8%）
        - 选择性接触：人们倾向于接触和自己原有立场一致的宣传
        - 交叉压力：受到相互矛盾的影响（比如宗教倾向和阶层倾向不一致）的选民，往往推迟做决定，对选举也不太关心
        - 人际影响：比大众传媒更能左右投票，对较晚做决定的人尤其明显
        - 两级传播与意见领袖：首次作为假说提出 → 见③
      - 意义：有限效果论的开端，打破了魔弹论；固定样本追踪调查成为经典研究方法
      - → 联系：高德特也参与了“火星人入侵”研究（第一阶段④）
    - ② 霍夫兰的说服研究 ★
      - 人物：卡尔·霍夫兰，美国心理学家，传播学“四大奠基人”之一
      - 二战陆军研究（成果见《大众传播实验》，1949）
        - 对象：美国陆军新兵
        - 材料：卡普拉执导的系列纪录片《我们为何而战》
        - 发现：看过影片的士兵对战争事实的了解明显增多；对相关问题的看法变化有限；参战积极性几乎没有提高
        - 一面提示与两面提示：对文化程度较低、原本就赞同的人，只讲一面的说法更有效；对文化程度较高、原本反对的人，正反两面都讲更有效，而且更能抵御之后的相反宣传
        - 休眠效果：有些看法的变化在看完影片一段时间后才显现，而且比刚看完时更明显
      - 耶鲁传播与态度改变研究（战后；《传播与说服》，1953）
        - 思路：说服效果取决于“谁说、说什么、对谁说”等条件，逐一用实验检验
        - 信源：可信度高的信源短期说服效果更好；时间长了，人们记住了内容却忘了信源，高、低可信度信源的效果趋于接近（休眠效果）
        - 信息：一面提示与两面提示；是否明确给出结论；恐惧诉求（过强的恐惧诉求未必有效）
        - 受众：个性、可说服性、所属群体的影响
      - 实验与调查结论的差异（1959）★
        - 霍夫兰在后续研究中指出：实验研究显示的效果通常比实地调查大
        - 原因一：实验中受试者被“强制接受”讯息；日常生活中，人们是根据自身兴趣自发接触信息
        - 原因二：效果的产生有时不是即时的，而实验多测量短期效果
        - 原因三：实验多选用容易改变的议题，调查涉及的往往是与人们切身相关、根深蒂固的态度
      - 意义：开创了说服研究的传统；发现效果受到多种条件的制约，支持了有限效果论
      - → 联系：在“刺激—反应”之间加入中介因素（对照第一阶段的理论资源）
    - ③ 《个人影响》：两级传播与意见领袖（迪凯特研究）★
      - 来源：伊里县研究中，拉扎斯菲尔德发现，讯息往往不是受众直接从媒体获得的，而是从大众传媒到意见领袖，再到一般群众，即“两级传播”
      - 验证：卡茨和拉扎斯菲尔德在伊利诺伊州迪凯特市开展研究（1945年调查，1955年出版《个人影响》）
      - 方法：访问约800名妇女，考察她们在日常购物、时尚、公共事务、看电影四个领域里受谁的影响较大
      - 发现
        - 在一定程度上印证了“两级传播”
        - 意见领袖分布在社会各个阶层，和受其影响的人往往属于同一群体
        - 不同领域有不同的意见领袖，很少有人在所有领域都是意见领袖
        - 意见领袖比一般人更多地接触大众传媒
      - 意见领袖（opinion leader）★：在人际传播网络中经常为他人提供信息、意见和建议，并对他人施加影响的“活跃分子”
      - 批评与修正：两级传播后来受到许多学者的批评和修正
        - 把传播过程简单化了：很多信息可以直接从媒介到达受众，不一定经过意见领袖；电视普及之后更是如此
        - 把人简单分成主动的意见领袖和被动的追随者，实际上意见领袖自己也受别人影响
        - 多级传播：罗杰斯在创新扩散研究中区分了“信息流”和“影响流”，信息可以一步直达，影响则往往要经过多级传递，于是提出“多级传播”（N级传播）
      - → 联系：卡茨后来转向“使用与满足”研究（第三阶段）
    - ④ 克拉珀《大众传播的效果》（1960）★
      - 人物：约瑟夫·克拉珀，曾在哥伦比亚大学应用社会研究局工作，后任哥伦比亚广播公司（CBS）社会研究部主任
      - 贡献：不仅梳理了此前二十多年的既有研究，被看作有限效果论的总结；还提出一种现象学转向
      - 现象学转向（phenomenistic approach）★：不把媒介当作传播效果唯一的影响因素，而是把媒介看作在整体情境中与其他因素共同起作用的一个因素
      - 五条概括（重点是前两条）
        - 大众传播通常不是产生效果的必要和充分条件，而是通过一系列中介因素起作用
        - 这些中介因素使大众传播成为强化现有状况的辅助因素，而不是唯一原因
        - 大众传播促成改变时，往往是因为中介因素失效、媒介效果变得直接，或者中介因素本身就在推动改变
        - 在某些情况下，大众传播似乎能直接产生效果
        - 大众传播的效力还受媒介和传播本身多种因素的影响（如信源、信息的组织方式、舆论气候等）
      - 强化论：因为有中介因素，大众传播主要起强化作用，而不是改变作用

  - 4、评价
    - 贡献
      - 纠正了魔弹论对媒介力量的夸大，看到了受众的个体差异和社会关系
      - 提出了选择性接触、两级传播、意见领袖、中介因素、休眠效果等重要概念
      - 大规模调查、固定样本追踪和控制实验让效果研究走向科学化，奠定了传播学实证研究的传统
    - 局限 ★
      - 低估了媒介的力量：主要测量短期的、个人层面的态度和行为改变，忽视了长期、累积、宏观的社会效果（如对人们认知和社会文化的影响）
      - 研究情境有限：伊里县研究发生在报纸和广播时代、政治倾向稳定的小县城，电视普及后情况发生了变化
      - 把“没有改变态度”等同于“效果有限”，忽视了强化本身也是一种重要效果
      - 回避了媒介所有权、控制与权力等问题（批判学派的批评，如吉特林1978年的《媒介社会学：主导范式》）
  - 5、向下一阶段过渡
    - 1959年贝雷尔森发表《传播研究的现状》，认为传播研究“正在枯萎”，引起施拉姆、卡茨等人的反驳
    - 卡茨在回应中提出，研究应少问“媒介对人做了什么”，多问“人用媒介做了什么” → 使用与满足
    - 电视在20世纪50—60年代迅速普及，研究者开始重新思考媒介的力量
    - 研究重心转移：从态度转向认知（议程设置），从短期转向长期累积（培养理论），从个人转向社会（知沟）→ 进入适度效果论阶段
  - 6、考点与易错点 ★
    - 名词解释｜有限效果论：20世纪40—60年代占主导地位的媒介效果观。它认为大众传播通常不是产生效果的必要和充分条件，而是通过既有倾向与选择性接触、群体规范、人际传播、意见领袖等中介因素起作用，主要效果是强化受众原有的态度。代表研究有伊里县研究、霍夫兰的说服研究、迪凯特研究，克拉珀《大众传播的效果》（1960）是其总结。它纠正了魔弹论的偏颇，但低估了媒介长期、宏观的影响
    - 名词解释｜两级传播：拉扎斯菲尔德等在伊里县研究（1940）中提出的假说，认为大众传播的信息往往先到达意见领袖，再由意见领袖传给一般受众。卡茨和拉扎斯菲尔德的迪凯特研究在一定程度上印证了它。它揭示了人际传播在大众传播效果中的作用，但把传播过程简单化了，后来被“多级传播”（N级传播）等模式修正
    - 名词解释｜意见领袖：在人际传播网络中经常为他人提供信息、意见和建议，并对他人施加影响的“活跃分子”。他们分布在社会各个阶层，不同领域有不同的意见领袖，而且比一般人更多地接触大众传媒
    - 名词解释｜选择性接触：受众倾向于接触与自己既有立场、态度一致或接近的信息，回避与之相反的信息。它和选择性理解、选择性记忆一起，被称为受众的“三个防卫圈”
    - 名词解释｜休眠效果：霍夫兰等人发现，有些说服效果不会马上出现，而是过一段时间才显现。例如可信度低的信源，信息的说服效果起初较小，一段时间后人们忘记了信源、只记得内容，效果反而增大
    - 易混：伊里县研究（1940，选举，《人民的选择》1944）vs 迪凯特研究（1945，日常生活四个领域，《个人影响》1955）
    - 易混：霍夫兰的两段研究。二战陆军研究（《大众传播实验》1949）vs 耶鲁研究（《传播与说服》1953）
    - 易错：两级传播是在伊里县研究中作为假说提出的，在迪凯特研究中得到验证
    - 易错：有限效果论不等于“媒介无效果论”
