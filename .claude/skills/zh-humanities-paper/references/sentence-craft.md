# 句子与措辞手册

作者常把一段话贴过来，只附一句很短的评语。这份文件的用途有两个：一是把这些评语对应到具体的毛病；二是汇总作者否决过的写法、AI 写作的痕迹，以及作者自己改稿时的习惯。

- 一、作者的短评，各指什么问题

## 一、作者的短评，各指什么问题

| 短评 | 通常指的问题 | 改法 |
|---|---|---|
| **幼稚** | 段首句只承担过渡（“然而……”“但……”“在这里……”），没有亮出本段的命题；用比喻代替判断（“被打开为”）；节末点名式回顾，好几位理论家并列，像在打分；表述虚（“有了新的形态”） | 段首写出命题；把比喻改成机制陈述；删去点名回顾，理论对话移到余论 |
| **杂糅** | 主语错位（例如“……的描述词……是征候”，词语本身不可能是征候）；限定语叠加；一句话塞了几层意思；“层面”之类的词重复 | 找准主语；只留一个限定；拆句；删掉冗余成分（“所谓”“描述词”“层面”） |
| **啰嗦** | 过渡句太长；元话语多；重复上文已经说过的内容 | 过渡句压到一句；删去路标式的话；只保留新信息 |
| **不太准确** | 词义程度与现象不符（“定向”）；概括超出原文；指向不明 | 用命名的四项检验逐一检查；回原文核对 |
| **太宽泛** | 概括词没有指向（“有所偏向”：什么的偏向？偏向哪里？） | 说清“是什么的”“朝向哪里” |
| **有点硬／没什么因果关系** | 转折没有逻辑依据，上文的局限与下文的路径之间没有真实的因果关系 | 让上文的局限直接引出下文；转折要有理由 |
| **不学术／跟下文没关系** | 句子只陈述一个事实（“这个词别人也用过”），没有论证功能 | 改写成判断，说出既有用法的局限，让下文顺势接上 |
| **戛然而止** | 段尾没有推进 | 补一句短而有深度的推进，不铺开新话题 |
| **激进／不规范** | 全称判断、贬义动词、反讽、断裂式叙述、暗示超越大家 | 见第二节 |
| **有 AI 味** | 见第三节 | 见第三节 |
| **感觉都不咋样** | 方案太套路化，如把概念标签塞进副标题 | 换思路，不要在原方案上微调 |
| **太空了／太肤浅** | 研究问题停在空泛的层面，或只是把对象现成的特征换个说法 | 落到具体困难，让问题能给同类研究或创作提供帮助 |
| **先射箭再画靶子** | 先有结论或作品特征，再回头编问题 | 从真实存在的创作或理论困难出发，作品只作案例 |
| **胡扯** | 编造了情节、动机、心理、伦理困境 | 删去；只写材料能证明的内容，缺的标【待补】 |
| **太玄了／不够准确也不学术／很不专业／这是一个学术概念？** | 自造的概念，或用日常说法冒充术语 | 改用学界已有的概念，见 `concept-naming.md` 第一节 |
| **拗口／太宽泛** | 题目或术语有重复成分，覆盖面过大（如“人物纪录片人物形象塑造”） | 删去重复，收窄研究角度 |
| **不对仗／很口语化** | 同级标题句式不一致；用了口语词（如“重返旧直播间的口述”） | 套用同级标题的句式，改成书面语（“过去与现在：记忆空间与现实空间的叠合”） |
| **我不太理解** | 关键词表意不清，或与相邻的概念对不上（如“对照”） | 换一个含义明确、能与同级概念对齐的词（“张力”，与“骨架”“线索”并列） |
| **没有逻辑顺承** | 几个理论或几章并列，没有递进 | 只留一个主线，各章由浅入深；辅助理论降为小节 |
| **给自己挖坑** | 研究起点依赖尚未定型的东西 | 换成稳定的起点 |
| **太单薄** | 一章只有一两节，展开不够 | 补到三到四节：总述→个案→呈现方式 |
| **老土／太普通／滑稽** | 名称（片名、题目）缺少分量，不贴切 | 贴切、庄重、有意味，与作品内容和论文主题呼应 |
| **太乱了**（格式） | 排版不规范 | 按学术格式排版，见 `degree-thesis.md` 第七节 |

## 二、被否决的表达与替代思路

| 被否决或应避免的 | 问题 | 替代思路 |
|---|---|---|
| 研究发现（用在理论文章里） | 暗示有经验发现 | 本文提出 |
| 以媒介考古学为方法 | 主张过强 | 借鉴媒介考古学 |
| 构成／正是／恰恰是 | 断言过强 | 可被理解为／可视为 |
| 必然／永远／从不／完全／只 | 全称判断 | 往往／难以／大多不／主要 |
| 却完全无视／症结 | 贬义、带情绪 | 而忽视了／问题 |
| 颇具反讽意味的是 | 修辞性反讽 | 删去，直接陈述 |
| 不再是……而是…… | 断裂式叙述 | 不只是……也是……／未必……也可能…… |
| 只是把原因从技术换成了社会；它们修正了答案，却没有触动问题本身 | 贬低他人、口号化 | 解释的重心则由技术移向了社会 |
| 恩斯特很可能忽略了 | 揣测并贬低大家 | 这一框架较少考虑到 |
| 未曾进入具体的机器 | 绝对化 | 较少进入具体的技术操作 |
| 仍停留于思辨 | 贬义 | 主要以哲学论证的形式提出 |
| 推荐系统几乎不排除任何内容 | 以偏概全 | 推荐系统固然也有审核、过滤与去重，但其权力更常以可见性梯度的形式运作 |
| 真正的共处包含批判，真正的共生要求责任 | 对仗口号 | 这种共处并不排斥批判，也要求承担责任 |
| 可在一定程度上理解为……在经验层面留下的征候 | 限定语叠加，主语错位 | 一个限定加一个判断，如“或可视为排序运作在经验中留下的征候” |
| 在此被打开为／得以照亮／获得回应 | 用比喻代替判断 | 直接陈述机制 |
| 现已被沿用至多领域 | 空泛 | 点明具体领域，并为下文服务，如“后被引入技术哲学与社会理论，用以理解……的回环结构” |
| 仍有进一步检视的空间…… | 啰嗦 | 本身仍值得进一步检视 |
| ……可辨认的历史形态……这一历史如何被叙述 | 不准确 | 让局限直接对准“以时代为单位的叙述方式” |
| 然而，调度并不止于当下。（作段首） | 段首只做过渡 | 承接上段的结论，同时给出本段的命题 |
| 定向 | 程度过强 | 视语境选用约束、引导、收敛等 |
| 有所偏向 | 指向不明 | 说清是什么的偏向、偏向哪里 |
| 趋于收敛 | 动态不全 | 在收敛与播撒之间往复 |
| 相互引发 | 因果动词与机制不符 | 往复；具体机制用“成为……的起点／依据”分别交代 |
| 循环（与“不闭合”连用） | 暗含首尾相接 | 回环 |
| 三角校准 | 生造，生硬 | 用作者已有的说法，或直接描述关系 |
| “交互”一词在某领域也已有使用 | 只交代“有人用过”，没有论证功能 | 既有研究在使用“X”这一概念时，仍以……为对象 |
| 恰恰说明（用于矛盾的研究发现） | 推断过强；矛盾也可能来自测量差异 | 提示 |
| 笔者认为 | 作者改稿时全部删去 | 直接陈述判断，或用“本文／本研究认为” |
| 但是不得不指出 | 套话 | 但是 |
| 熟人拍摄／拍摄距离／距离调适（作学术概念用） | 日常说法或自造词 | 旁观与介入、参与式等学界已有的说法 |
| 人近镜远（作题目） | 修饰性题目 | 用规范范式：“××视域下××的××研究——以××为例” |
| 重返旧直播间的口述（作节题） | 口语化，不对仗 | 记忆空间与现实空间的叠合 |
| 对照（作章名关键词） | 含义偏泛，读者不理解 | 张力 |

## 三、AI 写作痕迹清单

作者说过：“仍然有比较明显的 AI 书写痕迹”。被认可的版本与被否定的版本相比，差别主要在下面几处：

1. **空洞的元话语**：需要指出的是、值得注意的是、不得不指出、可以看到、由此可见、整体而言、综合上述……可以发现一些共同之处、具有重要的理论与现实意义。
   → 删去，直接说判断。
2. **抽象名词的罗列**：“涉及……、……、……以及……等多个层面”。
   → 选一个最重要的写透，或者用一个具体场景把几项串起来。
3. **缺少场景**：
   - 被认可的版本会写：“以一次常见的线上就医为例，患者打开医院的小程序后，往往先由智能导诊……；在等待接诊的过程中……；问诊结束之后……”；
   - 也会写时间上的具体片段：“患者可能在深夜向人工智能描述症状，第二天上午在平台上等待医生回复，到了晚上再……”。
   → 用一个时间顺序清楚的场景，代替抽象概括。
4. **缺少精确信息**：
   - 被认可的版本写的是“2025 年 8 月”“同年 10 月”“86.5%”“48 家”“一个月内扩展到 37 家”；
   - 政策文件给出全称和原文。
   → 能给出数字、日期、全称的地方，都给出来。
5. **没有一个统领性的观察**：
   - 被认可的版本先提出一个观察：“在医生之外，多了一个随时可以对话、也随时可以拿来与医生比较的对象”；
   - 再用“先看‘随时可以对话’的一面”“再看‘随时可以拿来比较’的一面”“参照还涉及权威”把后面几段串起来。
   → 先找到一个能统领几段的观察，再逐层展开，不要并列堆砌。
6. **对仗口号、三段排比、金句式收尾**。
   → 改成平实的陈述。
7. **“不再……而是……”“并非……而是……”过多**。
   → 多用“不只是……也是……”。
8. **用比喻性动词代替判断**：重塑、赋能、勾勒出……图景、打开……空间、照亮。
   → 改为陈述机制。
9. **叠加的限定语**。
   → 一句话只用一个限定。
10. **生造术语**。
    → 用作者的说法，或学界通行的概念。
11. **自我标榜或自我澄清**：“与已有研究不同，本文……”“本文的创新在于……”（在正文中）。
    → 删去，让差别从论证中显现。
12. **无法核实的否定判断**：“鲜少”“从未有研究”“尚无任何”。
    → 改成可核实的表述，如“较为多见的是……”“本文所见文献中尚未……”。
13. **路标和预告太多**：“下文将……”“这一问题留待第四部分讨论”“如前所述”。
    → 能删就删，小标题本身就是路标。
14. **句子太长**：作者改稿后，平均句长约 67 字。
    → 超过 80 字的句子考虑拆开。

## 四、段首句与段尾句

### 段首句

要求：承接上段的结论，同时亮出本段的命题。

被作者评为“幼稚”的段首句，以及当时给出的改法：

| 原句（问题） | 改法（方向） |
|---|---|
| 对象之间的关系进一步成为召回与排序的依据，内容的筛选也由此展开。（只是平铺事实） | 被标定的关系经由召回与排序转化为调度的依据，决定档案中的何种内容得以进入当下。 |
| archē 所含的“命令”之义在这里有了新的形态。（“有了新的形态”太虚） | 排序在技术上是候选项的先后安排，在档案层面则改变了 archē 所含“命令”之义的运作方式。 |
| 然而，调度并不止于当下。（只做过渡） | 调度所组织的当下，随即被回写为档案中的过去；推荐算法所依据的历史，因而本身就带有调度的印记。 |
| 但回写并不意味着重复只是同一者的再生产。（以“但”起头，没有命题） | 反馈回路放大既有偏好的倾向，并不意味着递归档案只是在再生产同一者。 |

右栏是当时给出的方向，作者没有逐条确认，用作参照即可。共同的做法：主语就是本段要讨论的那个机制，谓语给出判断，句中带着上段的结论。

### 段尾句

- **要做到**：推进一层，篇幅克制（“短小精悍”）。
- **常见的推进方式**：
  - 指出一个后果；
  - 点出一个更深的关系；
  - 提出一个尚待研究的问题；
  - 把本段的发现与核心问题连起来。
- **要避免**：
  - 复述本段；
  - 点名式的理论回顾；
  - 铺开新话题；
  - 以“……这些都是值得追问的细节”这类泛泛之语结束。

## 五、作者改稿时的习惯

这些习惯来自作者对 AI 初稿的亲手修改，是最直接的证据。

- **句子更短**：平均句长从约 77 字降到约 67 字。
- **多用“即”作解释**：从 6 处增加到 13 处。例如：“带入，即患者和医生带着什么进入这一环节”。
- **多用“例如”**：从 1 处增加到 7 处，后面接具体的场景。
- **多用“尚未”标出研究空白**：从 3 处增加到 9 处。还有“尚缺少研究”“尚少见于经验研究”“现有研究还没有追踪”等说法。
- **删去“笔者认为”**：初稿有 3 处，全部删去。
- **删去描述研究者动作的填充语**：
  - “许向东和王怡溪（2020）在梳理已有定义之后概括指出，‘……’”
    → “认为‘……’（许向东，王怡溪 2020）”
  - “匡文波和姜泽玮（2024）在归纳学界讨论的基础上，将……”
    → “如匡文波和姜泽玮（2024）将……”
- **主语前置，压缩表述**：
  - “关于智能传播的定义与内涵，国内外学者尚未形成共识”
    → “智能传播的定义与内涵在学界尚未形成共识”
  - “综合上述界定，可以发现一些共同之处，即”
    → “综上，”
- **直接以判断开头**：
  - 删去“从国外看，”；
  - “从国内看，”改为“以国内研究来看，”。
- **删去重复的说明**：
  - “二者是不同的研究对象，本研究分别加以考察”
    → “本研究将分别加以考察”；
  - “指向相近，并无根本差别”
    → “指向相近”。
- **删去路标和预告**：例如“这一问题留待第四部分讨论”“下文引用后两类证据时，将说明……”。
- **列举方式**：
  - 多个并列项写成一句，项与项之间用分号隔开，如四种智能媒介形态；
  - 述评用“第一……第五”编号，不用“首先、其次、再次、最后”。
- **大段删减**：
  - 把一节约 1500 字的研究分歧辨析，压成一段短概括；
  - 风险部分只保留一个最关键的条件和两个概念的界定；
  - 删去一整套学科分类及其协调段落。
  → 作者看重聚焦，不追求面面俱到。

## 六、常用的衔接与限定

**衔接**：
- 即；例如；换言之；据此；由此；前者……后者……；一方面……另一方面……
- 其一……其二……；一是……二是……；第一……第二……
- 综上；有鉴于此；在此基础上；与此同时；事实上（用于转入更深一层，不用来强调）

**限定**：
- 往往；大多；主要；未必；难以；在一定程度上（同一段里最多用一次）
- 或可视为；可被理解为；可能；尚待检验
- 尚未；尚缺少；较少

**表示推断**：
- 据此可以提出一个尚未被检验的设问：……
- 这提示……
- ……可能……，进而……

注意：编号方式要避免冲突。在“三类证据”内部又谈到两种研究时，用“前者／后者”，不要再用“第一类／第二类”。

## 七、诊断与替换的回复格式

作者贴一段话、附一句短评时，按下面的格式回复：

```
问题在于：……（一两句，指出具体病因，如“首句只承担过渡，没有给出本段的命题；‘被打开为’是比喻，代替了判断”。）

可改为：
> ……（替换后的完整句子或段落，可以直接粘贴）

[如有必要] 另一种写法：
> ……

[如有] 连带修改：第X节“……”中的“……”也需改为“……”，以保持术语一致。
```

不写长篇的道歉或自我解释。作者对改法不满意时（如“也不太好”），先重新诊断，换一个思路，不要在原方案上做细微调整。
