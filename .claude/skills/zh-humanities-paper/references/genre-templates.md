# 各类文体的结构模板

这份文件给出作者常写的几类文体的骨架。它们都来自作者认可的稿件和范文。

骨架只规定每一部分承担什么功能，具体篇幅和小节数量随题目调整。不要为了“填满”模板而补内容。作者偏好的始终是聚焦，而不是面面俱到。

## 目录

- 一、理论思辨论文
- 二、质性经验研究
- 三、文献综述
- 四、研究计划与开题报告
- 五、摘要与关键词
- 六、题目与小标题
- 七、余论、讨论与结论
- 八、篇幅与图表

## 一、理论思辨论文

参照：作者的《媒介时间性的档案之维》，以及范文《分化与交叠》《连接与反连接》《智能机器的多重媒介意涵》。

```
一、前言（或引言，不一定单列标题）
   - 一个具体局限：既有研究在叙述方式、分析单位或看待技术的方式上的局限。
     例：媒介时间研究“以时代为单位”叙述，把媒介当作黑箱。
   - 这个局限为什么重要：它使哪一类问题无法被提出。
   - 一两句话预告本文的路径。核心问题不必在这里完整提出。
二、理论路径与核心概念
   - 由上文的局限引出理论资源。理论家出场时，要回答前言提出的困难。
   - 理论资源的组合，写明“本文将……与……相联系”。
   - 界定核心概念：本义、学者的发展、本文的取义、判别条件，每步都有出处。
   - 提出全文唯一的核心问题，并说明它分解为哪几个环节。
三、四……（按机制的环节展开，每节对应核心问题的一个环节）
   - 小标题用“关键词：命题”的形式，如“写入：先于过去的未来”。
   - 用工程文献、技术细节、具体案例讲清机制，概念与机制一一对应。
   - 节末推进一层，不做点名式的理论回顾。
余论（或结语）
   - 理论回馈：本文的分析对所借用的理论意味着什么。姿态是对话、补充、在具体对象上的检验，不是超越。
   - 价值或伦理追问：例如媒介伦理、人的自主、制度。
   - 承认限度，提出开放问题。
```

## 二、质性经验研究

参照：范文《远程办公与智能工作平台中的时间政治》《网络化身体》。

```
一、研究缘起
   - 现象（具体，带时间和数据）→ 反常或悖论 → 现象背后更深一层的问题 → 现有视角为什么不够。
二、文献回顾
   - 两到三条线索，每条用“从 A 到 B”梳理概念的演进，节点带年份。
   - 每条线索末尾用一句话总括演进方向，并指出局限。
   - 引出本文的理论概念：沿思想史梳理，再写“有鉴于此，本文将 X 定义为……”，
     并说明它为什么适合这个对象。
   - 研究问题：一般两个，编号，具体到可以回答。
三、研究方法与设计
   - 方法、时间段、抽样方式、样本量；受访者信息表（这里用表格是恰当的）。
   - 研究者自己的观察位置。
   - 二次使用的材料，要说明原研究与本文问题的差异。
四、发现一（总标题用“意象：概括”）
   （一）（二）（三）各对应一个层面，如结构、动态、规则。
   每个小节：命题句 → 肯定的一面加引语 → “但……”复杂化，给出另一面的引语或数据
            → 理论阐释 → 推进一层。
五、发现二或行动者的回应（如抵抗、调适、策略）
   - 列出两到三种策略，每种附引语。
   - 最后回头审视：这些策略的限度，背后的结构性原因。
六、结论（与讨论）
   - 理论贡献：本文的概念在既有理论之外提供了什么。
   - 发现回顾，一段即可。
   - 结构性批判。
   - 制度、设计或实践层面的路径，以具体的法律、标准、案例为依据。
```

写引语的规则：
- 引语要短，编号（S1、S2……），嵌进句子里。
- 引语用来佐证命题，不代替命题。
- 不渲染受访者的情绪，用平实的语言转述。

## 三、文献综述

参照：作者亲手改定的博士研究计划文献综述，以及作者给出的修改意见。

```
导言（一段）
   - 研究分布在哪些领域，为什么分散。
   - 本部分的组织线索（如“就医历程”），以及各部分分别做什么、为什么这样排。
（一）核心概念的辨析与研究范围
   1. 核心概念的定义：按切入视角归为几类，每类附代表性定义，直接引语附出处；
      再用“综上”归纳共同点与差异，最后给出本研究的界定。
   2. 相近概念的辨析：每个概念把现象看成什么、技术处在什么位置、见于哪些领域；
      最后一段做术语约定（“在用语上……”）。
   3. 分析单位与研究范围：
      - 分析单位借鉴什么已有概念、做了什么改动；
      - 纳入与排除的标准，写成文字；
      - 证据分层：直接证据、邻近证据、一般性证据，各自的适用程度和迁移限度。
（二）发展脉络
   - 国外、国内分别分期，每期写节点（政策文件、技术事件）、代表研究、方法特点。
   - 段末一句话总括重心的转移，并指出尚少见于研究的部分。
   - 段首直接以判断开头，不写“从国外看，”。
（三）机制研究（按过程组织，不按议题）
   - 开头说明几条线索分别处在什么层次、彼此如何关联（理论前提、关系结构、心理过程、工作组织）。
   - 按环节展开，每个环节关注三点：带入、交互、带出。
   - 同一线索在不同环节再次出现时，说明它承担的解释任务有什么不同。
   - 环节末尾用一句话写现有研究“尚未”考察的方面。
（四）风险或后果研究（解释任务与机制部分不同）
   - 理论传统一段。
   - 只抓一到两个最关键的条件，不罗列类型。
   - 界定本研究的“风险”与“调适”等概念。
（五）研究述评
   - 先用一段肯定既有研究在对象、议题、视角三方面的进展。
   - 再写不足，用“第一……第五”，分别从研究对象、研究过程、研究内容、
     研究方法、研究情境五个角度写；每一条都有具体依据，不只是空泛的断言。
   - 最后一段引出本研究的切入点，与正文的术语完全一致。
```

几点提醒：
- 综述写成文字，不用表格。
- 同一篇文献在不同部分出现时，第二次要给出新的分析。
- 实验发现的长篇罗列要压缩，只保留与论证相关的结论。
- 分歧要分清是同一问题上的矛盾，还是在回答不同的问题。
- 不写“笔者认为”。
- 推断要写成推断。

## 四、研究计划与开题报告

参照：作者认可的“选题缘起与研究意义”现行版本。这一版是在作者批评“AI 痕迹明显”之后改出来的。

```
一、选题缘起与研究意义
（一）选题缘起
   1. 宏观驱动，一般写政策、技术、社会需求三方面：
      - 政策：文件全称、印发机关、年月，直接引语附出处；也写政策划定的边界
        （如“严禁使用人工智能等自动生成处方”）。
      - 技术：具体模型、具体数字（准确率、部署医院数、时间节点）。
      - 社会需求：权威统计（如 CNNIC 报告的用户规模），再加一个生活化的场景
        （深夜身体不适时……）。
      - 段末说明中国情境的典型性。
   2. 变化的过程：用一次具体经历的时间顺序展开，例如患者从打开小程序到诊后随访的全过程。
   3. 变化带来的问题：
      - 先提出一个统领性的观察，如“在医生之外，多了一个随时可以对话、
        也随时可以拿来比较的对象”；
      - 再分几个方面逐层展开（“先看……的一面”“再看……的一面”），
        每层落到一个理论概念和一项研究；
      - 最后把几个问题收拢为一条链，引出风险。
   4. 核心概念与问题的提出：
      - 相近研究的局限 → 理论视角 → 核心概念的定义 → 纳入与排除的标准
        → 两个层面的研究问题。
（二）研究意义
   1. 理论意义：一到两段，说明对哪个领域的哪个前提有推进，不夸大。
   2. 实践意义：一段，落到具体的使用者（医生、患者、平台、机构）。
二、文献综述（见第三节）
三、研究问题、研究方法、创新与难点：控制篇幅，写成连续的文字。
```

- 作者给出的“几条思考”，要融进整体框架，不要逐条罗列。
- 以某本书为范本时，学它的推理方式和语言，但正文里不要写明本研究是在推进这本书。

## 五、摘要与关键词

**摘要**：四到六句，二百五十到三百五十字。

- **理论文**：
  - 第一句交代现象或论域；
  - 中间几句依次对应正文各部分的论点，直接陈述；
  - 最后一句落到理论意义或伦理追问。
- **经验研究**：
  - 背景一句；
  - 理论视角一句；
  - “研究发现”之后列出主要发现，两到三句；
  - 建议或意义一句。

摘要中的术语与正文完全一致，核心概念必须出现。理论文可以不用“本文”，直接陈述；需要时也可以写“本文提出……”。

**关键词**：三到五个，包括核心概念、研究对象、理论视角。

## 六、题目与小标题

本节针对期刊论文。学位论文的题目用规范范式：“××视域下××（作品类型或题材）××（研究角度）研究——以《××》为例”，详见 `degree-thesis.md` 第四节。

**期刊论文题目**的几种形态（参照范文）：
- 对举式：“A 与 B：X 的 Y”，如“分化与交叠：移动时代的时间”“连接与反连接：互联网法则的摇摆”；
- 概念加意象：“核心概念：意象一与意象二”，如“网络化身体：病毒与补丁”；
- 平实式：“X 的多重意涵及其影响”“X 与 Y 中的 Z”；
- 判断式：用一个有张力的判断串起全文，如“先于过去的未来：……”。

**题目的要求**：
- 主标题短（十二字以内为宜），有张力或判断；
- 副标题点明对象，不重复主标题；
- 不把概念标签机械塞进副标题（“……：作为‘X’的 Y”被作者评为“都不咋样”）；
- 与核心问题、核心概念呼应。

**小标题**：
- 说出本节的命题，不只给出话题。“写入：先于过去的未来”优于“写入环节分析”。
- 同级小标题语法平行：
  - 用“关键词：命题短语”，如“时间转移：移动办公与在线可见”；
  - 或用同一个词领起，如“反连接：一种情境性选择”“反连接：对用户的新赋权”；
  - 或用“从 A 到 B”。
- 小标题的用词必须与摘要、核心问题一致，如“调取”和“调度”只能用一个。

给题目方案时，按第六节的形态给出三到五个，说明每个强调什么、有什么风险。如果作者否定了一轮，就换思路，不要在原方案上微调。

## 七、余论、讨论与结论

- **讨论**：概念带来几点启发，每点与一位理论家对话，说明本文的概念在哪个维度上补充或调整了既有理论。
  - 例：“网络化的”（networked）与卡斯特所说的静态的“网络”（network）的区分。
- **理论回馈**：用“使类似判断有可能在……层面得到检验”“或可在……获得一种技术回应”这类克制的表述，不说“证明了”“超越了”。
- **价值追问**：落到人的自由、权力、伦理、制度，可以用问句收束。
- **限度**：承认答案不是唯一的，指出尚待研究的问题。
- **不要**：在各节末尾点名打分；用煽情的省略号收尾；在结论里引入新的材料。

## 八、篇幅与图表

- 作者明确要求“注意控制篇幅”。起草时宁短勿长，先交一个精炼的版本。
- **表格**：概念比较和文献归纳一律写成文字；受访者信息、统计数据可以用表。
- **图**：一篇文章至多一张核心结构图。
  - 形态由概念本身决定，不套模板。例如用沿时间轴前进、回环而不闭合的线圈，表示“在收敛与播撒之间往复”。
  - 风格为灰度、简洁，接近期刊排版。
  - 图中每个元素都对应正文的具体论点。
  - 概念改了，图同步改。
  - 图注只写必要的说明，不重复正文。
- 删除图表时，指向它的措辞一并修改（“如表 4 所示”“图 1 中”），表号顺延。
