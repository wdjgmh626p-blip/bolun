# 引文与文献规范

作者曾要求对全文引文做逐条核查：“出处是否正确，是否原句引用，有没有误读，有没有漏引或多引，如果有遗漏贴出完整的引用，如果找不到就不引了。”这份文件把这条要求展开成可以操作的规则。

## 一、底线

- **不编造任何文献、数据、页码、引文或出版信息。**
- 不确定的，标【待核】，并写明需要核对什么（页码、原句、年份、作者人数）。
- 查不到出处的，建议删去，不能凭印象保留。
- 凭记忆核对和查到原文核对，是两回事，汇报时要分开说。
- 提出的推断不是已有研究的发现，正文中要用“可能”“尚待检验”等标明，并在交付说明里单独列出。

## 二、四种表述的标注

| 类型 | 写法 | 标注 |
|---|---|---|
| 原文的直接引语 | 加引号 | 必须有页码；外文附原文或注明译者 |
| 转述（对原作者观点的概括） | 不加引号 | 作者—年份；概括范围较小时附页码 |
| 他人对原作者的解读 | 写明“按照某某的解读”“某某认为，德里达……” | 标解读者的出处，不标原作者 |
| 本文自己的概括 | 不加引号，可写“本文将其概括为” | 不标出处；不能写得像引文 |

其他规则：
- 只读到二手文献时，标“（某某，年份，转引自某某，年份：页码）”。
- 延伸阅读或观点相近的文献，标“参见”。
- 把几位理论家联系起来，是本文自己的操作，写“本文将……与……相联系”，不能写成原作者本人的做法。
- 同一原文的直接引语，在全文各处必须逐字一致。
- 直接引语照原文抄录，不改动原句。用于界定的引语，宜用权威期刊、知名学者的原文原句。

## 三、格式

格式以目标期刊的体例为准。作者的论文和范文用过三种体例：作者—年份制、脚注制（①②）、文末编号制（[1][2]）。没有指定时，默认用作者—年份制。无论哪种，全文只用一种，并且统一。

### 作者—年份制，文中常见写法

- 中文单个作者：曹博林（2021）认为……；或……（曹博林，2021）。
- 中文两位作者：（许向东、王怡溪，2020）。作者之间用顿号，年份前用中文逗号。也可写作“匡文波和姜泽玮（2024）”。
- 中文三位及以上作者：方兴东等（2025）。
- 外文单个作者：Guzman（2018）；（Guzman, 2018）。
- 外文两位作者：Guzman 和 Lewis（2020）；（Guzman and Lewis, 2020）。
- 外文三位及以上作者：Hancock 等（2020）；（Hancock et al., 2020）。
- 带页码：（Hui，2019：1，4）；（Ernst，2013：57）。
- 多条并列：（Garcia et al., 2024；Tai-Seale et al., 2024）。各条之间用中文分号，按年份或作者排序，全文统一。
- 同一作者同一年有多篇：2024a、2024b。

### 要逐项检查的细节

- 合著不能写成独著。例：“她还（2022）”应改为“她还与代文犊犊（2022）”。
- 多位作者用复数代词。例：Hancock 等是多位作者，应写“在他们的理解中”。
- 括号里的中英文标点、and 与 & 不要混用。
- 引号后不要多出句号，例如“……”。（作者，年份）。
- 同一文献的期刊版和单行本，页码不能混用。例：《档案热》就有期刊版和单行本。
- 正文中引用了的，参考文献表里必须有；参考文献表里有的，正文中必须引用到。改稿时如果删了引文，要提醒作者同步删去参考文献条目。

## 四、人名

- 遵循目标期刊的体例，全文统一。常见的两种做法：
  - **理论论文**中的经典理论家：首次出现写“中译名（原文名）”，如“恩斯特（Wolfgang Ernst）”“布鲁诺·拉图尔（Bruno Latour）”，之后只写中译名。
  - **实证文献较多的综述**：外国研究者统一用原文姓名，如“Hancock 等（2020）”，不音译。
- 不要混用：有的音译加原文，有的只写原文。
- 中译名用通行译法，如拉图尔、德里达、斯蒂格勒、基特勒、彼得斯、韩炳哲、罗萨。

## 五、核查流程与汇报格式

### 流程

1. 逐条列出正文中的引文和出处。
2. 能联网检索的，先找原文：外文优先找原版，中文优先找期刊原文或中国知网信息。
3. 逐条检查以下几项：
   - 出处信息是否正确（作者、年份、题目、刊名、卷期、页码）；
   - 直接引语是否与原文逐字一致；
   - 转述是否超出原文、有无断章取义（要放回原文语境看）；
   - 有无漏引（用了观点却没标出处）或多引（引了却与句子无关）；
   - 有无二手引用未标“转引自”；
   - 译文是否准确。
4. 修正后给出完整的参考文献条目。查不到的，建议删去。

### 汇报格式

| 位置 | 引文或说法 | 问题 | 处理 | 核查状态 |
|---|---|---|---|---|
| 二（一）第2段 | “……”（福柯，1977：页码） | 页码错误 | 改为第 X 页 | 已对照原书 |
| …… | …… | 把桑德博特的转述当作德里达原话 | 改为“按照桑德博特的解读” | 已对照 |
| …… | …… | 找不到出处 | 建议删去 | 未找到 |

最后单独列出两项：
- **未核实**：哪些引文没有核，或只凭记忆核对；
- **需补入参考文献表**：哪些条目要补。

## 六、补充中文文献

作者的要求是：“中文引用太少……但一定要贴切适配，宁缺毋滥。”

- **数量**：要体现与国内研究的对话。
- **贴切**：每一条都放在与它的论点直接对应的句子上，不为凑数而引。
- **来源**：
  - 优先权威期刊，如《新闻与传播研究》《国际新闻界》《新闻大学》《新闻记者》《现代传播》《南京社会科学》，以及相关学科的权威刊物；
  - 优先知名学者的原文。
- **时效**：既要有经典权威，也要有当下前沿。
- **与最相近的国内研究**：在论证中自然带出，不单列一段比较。例如：“国内研究亦曾借其‘前馈’概念讨论数字媒介的时间性（戴宇辰，柳嘉慜，2024）”。
- **作者给了文献清单时**：先通读，再挑出真正能加强论述的，说明每一条放在哪一句、为什么放在那里。
- **修改方式**：如果要求“只改文献，不改表述”，新增的文献只放进已有的句子里，用颜色或加粗标出，不另写新句。

## 七、以往核查中发现的错误类型

| 类型 | 例子 |
|---|---|
| 页码错误 | 福柯、卡斯特、斯蒂格勒的引文页码 |
| 引文与原文不符 | 恩斯特多处引文，对照原书 PDF 逐条核对后才改正 |
| 张冠李戴 | 把马诺维奇辨析的“常见观念”当作他本人的正面论点，后改引 Bolter 和 Grusin 的“再媒介化” |
| 把解读当原话 | 把桑德博特的转述当作德里达的原话 |
| 版本混用 | 《档案热》期刊版和单行本的页码混用 |
| 二手引用未标注 | 罗萨的观点应标“转引自” |
| 误译 | “逻辑互连”应为“后勤式互连” |
| 脱离语境 | 斯蒂格勒的“短路”出自药理学语境，原文是“可能造成”，不是“必然导致” |
| 概括超出原文 | 对汉森“前馈”的概括超出了原文 |
| 概念溯源错误 | 误用与弃用这对概念出自 Parasuraman 和 Riley（1997），Lee 和 See（2004）是沿用 |
| 与所引数据矛盾 | 正文写“生成式人工智能总能提供正确回答”，同一段引的数据却是 94.9% |
