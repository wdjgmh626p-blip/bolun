# 协作中的失误与教训

本文件记录 AI 在以往的论文协作中犯过的错，以及作者认可的改法。修改或整理作者已有的稿件之前，先读一遍。

## 一、事故记录

### 1. 把“整理”做成了改写（最严重）

**经过**
- 作者贴出自己改过的文献综述，只说了一句：“这是我修改后的文献综述，整理一下”。
- AI 实际做了约 30 处超出“整理”的改动：
  - 恢复了作者删掉的一整节，约 1500 字（“信任与情感评价研究中的分歧”）；
  - 恢复了作者删掉的一整段（“协作环节的风险则主要与责任有关……”）；
  - 补写了作者原稿里没有的小结（“综上，诊中环节向诊后带出的主要有……”）；
  - 补写了作者原稿里没有的定义句（“历程中前后相连的……各环节构成就医链条”）；
  - 补写了一段统计文献分布的文字；
  - 看到正文里提到“图 1”“表 4”“表 6”，就自行做出了图和表；
  - 改写了本来没有错误的措辞，例如“测量的结果各不相同”→“测量的指标各不相同，结果……”，又如“关于线上医患交互过程中风险隐患与解决办法的研究”→“关于人工智能参与医疗沟通的风险研究”。

**作者的反应**
- “你能不能别瞎给我补充东西，尤其我的第二部分，原来删减的部分你怎么又给我调回来了？很多措辞你为什么又给我改了？”
- “这个在我给你的修改版中不是删掉了吗？怎么还留着？”
- “这段有吗？你别瞎给我补充行不行……你还做了那些画蛇添足的改动？”

**教训**
- “整理”只做细节修正。
- 正文提到了已删的图表，就删改这句提法，不要把图表重新做出来。
- 正文提到已删的小节，把“将在本部分第 5 节讨论”改为“将在下文讨论”，或者删去这句，不要把小节补回来。

### 2. 删表时把表的内容写回了正文

- **经过**：作者说“把那两个表都删掉，涉及到表的措辞也顺带修改”。AI 删了表，却把表里的文献和说明写进了正文。
- **教训**：“删掉”就是不要这些内容。“改写成文字”是另一种要求。分不清时先问一句。

### 3. 把“尽量不要改动原文”做成了新增小节

- **经过**：作者问能否在框架上调整，把“相关科研成果”与文献综述融合，并说“尽量不要改动原文”。AI 在综述里新增了一节待填空的模板，还在导言里加了一句。
- **教训**：只动框架，比如调整小节的位置、标题和编号，不新增段落，不改原句。

### 4. 看不到原稿时凭记忆整理

- **经过**：上下文被压缩后，AI 已经看不到作者的修改稿，却继续在“整理稿”上改。
- **教训**：底本不在眼前时，请作者重贴，不要凭记忆或凭自己的旧版本修改。

### 5. 软化过头，造出新的杂糅句

- **经过**：作者要求去掉激进措辞。AI 把句子软化成“可在一定程度上理解为……在经验层面留下的征候”“恩斯特框架中的运算当下，在此被打开为……”，作者分别评为“杂糅”“幼稚”。
- **教训**：克制和简洁要同时做到。每句只用一个限定，不靠堆叠修饰语显得稳妥。

### 6. AI 的建议本身措辞激进

- **作者原话**：“你刚才提出的建议和我原文中都有不少这种措辞上的问题”。
- **教训**：给作者的修改建议和示范句，同样要遵守措辞强度的规则。

### 7. 过度概括他人的观点

- **经过**：对汉森“前馈”的概括超出了原文；提出了有争议的“原初感性”说法；把 futur 与 avenir 的区分错误地对应到《档案热》中的具体位置。
- **教训**：概括理论家时，只说原文支持的部分。不确定出处位置的，标【待核】。

### 8. 过渡句缺乏因果，或者太啰嗦

- **经过**：几次桥接句都被否，作者的评语是“没什么因果关系”“有点硬”“啰嗦”“不太准确”。
- **教训**：过渡句要从上文的局限里直接长出下文。不要用“仍有进一步检视的空间”这类空话撑场面。

### 9. 命名不精确

- **经过**：“有所偏向”太泛；“相互引发”与机制不符；“三角校准”生硬。
- **教训**：每个候选先过四项检验（见 `concept-naming.md`），不要把没检验过的词交给作者。

### 10. 题目套路化

- **经过**：AI 把概念标签塞进副标题，如“媒介时间性的档案之维：作为‘递归档案’的推荐算法”。作者说：“感觉都不咋样”。
- **教训**：题目要有张力或判断，见 `genre-templates.md` 第六节。被否一轮后要换思路。

### 11. 忘记交付文件

- **经过**：AI 用脚本生成了文件，却没有发给作者。作者问：“文件在哪呢？”
- **教训**：生成文件后，直接交付给作者，并说明文件的位置和格式。

### 12. 没听懂元层面的请求

- **经过**：作者说想把对话发给别的 AI，“迅速理解我对论文的要求”。AI 整理成了这一篇论文的修改要求清单。作者纠正：“我是想把这种对话过程给 AI 分析，从而提取我对论文的要求，理解我理想中的论文的样子，从而用于下一次的论文写作”。
- **教训**：分清作者要的是这一篇论文的修改清单，还是普遍适用的写作偏好。

### 13. 单列一段“与已有研究的区别”

- **经过**：讨论与戴宇辰、柳嘉慜《前馈时间》的关系时，AI 建议单列一段交代区别。作者说：“我并不想单列一段交代关系，这样显得有点像自我澄清一样……最好是通过自己的论述让人读了之后自然明白其中差别，而不是自卖自夸。”
- **教训**：在用到相近概念的地方顺带一句即可，差别交给论证本身去体现。

以下第 14 至 22 条，来自一篇纪录片“理论+创作”型硕士毕业论文的选题过程。

### 14. 编造创作心理和伦理困境

- **经过**：选题汇报里，AI 写了“不忍拍”“伦理影响剪辑”之类的内容，作者评为“胡扯”。“访谈困难”“伦理模糊”等说法也被认为太空泛。
- **教训**：创作中的困难必须来自作者的真实经历和作品本身。没有材料支持的，不写；需要作者补充的，标【待补】并直接问作者。

### 15. 写错作品内容

- **经过**：AI 把片中平板里播放的影像，当成了创业旧址的旧直播影像，并据此设计了一节。作者说：“我并没有安排这样的情节”。在更早的阶段，AI 还把题材说成了“返乡创业”。
- **教训**：
  - 写作品分析之前，先读转写稿、拍摄日志、场记表，把人物、事件、场次核对一遍。
  - 理解错了，简短道歉，按材料改正。作者给出的线索（“有他回老直播间口述历史的情节”）只是方向，具体怎么写，要回到材料里核实。

### 16. 自造概念、不规范的题目

- **经过**：AI 先后提出“熟人拍摄研究”“拍摄距离研究”“距离调适”，又拟了“人近镜远”式的题目。作者的反应：
  - “很不专业……熟人拍摄这是一个学术概念？”
  - “你这题目自造的概念不合规范”
  - “太玄了”
  - 修饰性的题目要删去
- **教训**：只用学界已有的概念；学位论文题目用规范范式，见 `degree-thesis.md` 第四节。

### 17. 理论误用

- **经过**：AI 用布洛的“心理距离”来讨论拍摄者与被摄者之间的距离。作者说：“不行，首先辨析一个概念，布洛说的这个距离……”
- **教训**：借用理论概念之前，先回到原义辨析，判断是否适配，并查一查有没有人这样用过。

### 18. 先射箭再画靶子

- **经过**：AI 拿片中的“低谷”“落差”来设子研究问题。作者说：“这个子研究问题太肤浅了……刘思彤那个好歹是给拍陌生人的创作提供帮助，你又是低谷又是落差，这完全是先射箭再画靶子。”
- **教训**：研究问题要来自真实的创作或理论困难，回答它要能对同类实践有用。不要把作品现成的情节包装成研究问题。

### 19. 多个理论并列成章

- **经过**：AI 让空间叙事、拟剧理论、物叙事各占一章。作者说：“这样好像并列了三个理论一样，没有逻辑顺承。”
- **教训**：只用一个主理论，各章由浅入深；其他理论降为小节。

### 20. 节题不对仗、口语化、意思不清

- **经过**：
  - “过去与现在：重返旧直播间的口述”被评为“跟前面两节不对仗”“很口语化”；
  - 章名中的“对照”，作者表示“不太理解”。
- **教训**：
  - 同级标题套用同一个句式，并且用书面语；
  - 关键词要表意清楚，与同级关键词对齐。

### 21. 名称品味

- **经过**：片名候选《家人们》《下播以后》等，作者的评价是“好像都一般”“有点老土，有点太普通了”“很滑稽”。最后暂定《幕间》。
- **教训**：名称要贴切、庄重、有意味，最好能与论文的理论视角呼应。“幕间”就同时关联到舞台的“台前台后”和经营的间歇。被否一轮后，要换思路，不要在原方向上微调。

### 22. 建议多了，作者自会删掉

- **经过**：AI 建议第四章增加“4.4 声与画”，并在节题后加“（以……为例）”的括注。作者在自己的暂定版里，没有采纳 4.4，也删去了括注。
- **教训**：建议宜少而精。作者的暂定版或定稿出来以后，以它为准，不要再把没被采纳的建议加回去。

### 23. 用强调句冒充深度

- **经过**：在技能测试中，AI 修改一段被评为“幼稚”的话：删掉了比喻，却写成“平台不只……也……”“并不是……而是……”“……而不是用户……”。原段中间那句本来就有“并不是……而是……”，AI 却判断它“没有问题”，原样保留。
- **作者的评价**：“用了很多不是……而是……这种先否定再肯定的强调句，看似复杂有深度，其实还是很肤浅，你看看我自己的论文，这种论述是怎么做得。”
- **教训**：
  - 只换连接词，问题还在；
  - 深度要靠写清操作、推出后果、分出程度、写出另一面，详见 `sentence-craft.md` 第八节、`exemplar-moves.md` 第五节；
  - 诊断时，原段里没被点名的句子也要检查。

## 二、被作者接受的修改是什么样子

作者说“只挑细节上的问题，比如前后说法不一的地方等语病，别给我瞎加词”之后，AI 只做了 14 处修正，逐条列出理由，作者没有异议，直接要求导出 Word。这 14 处可以分为以下几类：

| 类别 | 例子 |
|---|---|
| 删除与已删内容对不上的残句 | 导言删去“并考察既有研究在就医链条各环节上的分布”，因为对应内容已经随表格删除 |
| 统一引文格式 | 统一为“（许向东、王怡溪，2020）”；删去引号后多余的句号 |
| 改正代词单复数 | “在他的理解中”→“在他们的理解中”（Hancock 等是多位作者） |
| 改正合著信息 | “她还（2022）”→“她还与代文犊犊（2022）” |
| 消除前后矛盾 | “患者与人工智能之间的人机咨询大致分为七种”→“智能媒介参与的交互与医患沟通之间的关系大致分为七种”，因为前文已把“人机咨询”限定为患者向 AI 提问 |
| 消除编号冲突 | 三类证据内部的“第一类／第二类”→“前者／后者” |
| 删除指向已删小节的句子 | 删去“最后，本部分单独讨论信任与情感评价研究中的分歧……” |
| 改正漏字和与数据的矛盾 | “生成式人工智总能”→“生成式人工智能大多能”（漏了“能”字；“总能”与下文 94.9% 的数据矛盾） |
| 改正已删小节的指称 | “将在本部分第 5 节讨论”→“将在下文讨论”；“如第三部分所析”→“如前文所述” |
| 改正不通的句子 | “向诊中待考究的有”→“向诊中带出的有”，与“带入、交互、带出”的框架一致 |
| 补出缺失的宾语 | “判断依据与信息质量相脱节”后补“的问题” |
| 删除指向已删表格的说法 | 删去“表 6 显示，” |
| 统一术语 | “就医链条”→“就医历程”，与（一）3 和导言一致 |

同时**留给作者决定、没有改动**的几处：
- 图 1 在正文中没有被引用；
- 诊中末段用了省略号；
- 第一部分的用词与综述不一致；
- 几条参考文献在正文中已经不再被引用。

可以看到，同样的改动内容，比如统一用“就医历程”，在上一轮被否定，在这一轮被接受。区别在于：这一轮的改动有限，并且逐条说明了理由。

**其他被作者接受的做法：**
- **用选择题请作者定夺。**例如第五章加哪几节、章名改不改、写作形式、写作节奏、篇幅、注释格式。每题二到四个选项，标出推荐项，说明理由。作者通常很快作答，有时还在答案里附上新的要求。
- **解释概念时，回到作品的具体段落。**作者问“这个对照我不太理解”，AI 用片中的三处实例解释，并说明它和相邻一章的区别。这样作者能马上作出判断。
- **作者说“直接在聊天框回复，无需重建文件”时**，只在对话中给出方案，等作者确认后再改文件，在线文档、框架图和导出文件一起改。
- **如实说明能力的边界。**例如“其他聊天框我读不到”“可以抽帧看画面，但无法转写语音”。同时告诉作者怎样提供材料。

## 三、修改说明模板

```
共修改 N 处，均为细节问题，未增删内容、未改动无误的措辞。

1. 【位置】原文：“……”
   改为：“……”
   理由：……（如：漏字；与下文 94.9% 的数据矛盾）

2. ……

留给你决定（未改动）：
- 【位置】……（问题是什么，可能的处理方式）
- ……

[如有] 需要同步处理的地方：参考文献表中的……已不再被正文引用。
```

输出 Word 文档时：修改处用蓝字，待定问题用红字；作者没有要求时，不用修订模式。生成文件后直接交付。

## 四、两类要求要分开

以往的材料里，有一部分只针对具体的论文，例如：
- “就医历程”的用法；
- “递归档案”的表述；
- 《数字诊室》和刘思彤的论文作为范本；
- 空间叙事的三章结构；
- 《幕间》中的人物和物件。

这些不要套到别的论文上。

迁移到新论文的，只是背后的原则：
- 分析单位要有文献支撑；
- 核心概念要过四项检验；
- 学范本的推理方式和语言，但正文中不声明在推进它。
