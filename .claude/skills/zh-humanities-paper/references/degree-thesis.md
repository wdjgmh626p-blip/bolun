# 学位论文：选题、汇报与“理论+创作”型论文

这份文件整理自一篇戏剧与影视专业硕士毕业论文的选题和写作准备过程。论文属于“理论+创作”型：毕业作品是一部约 35 分钟的纪录片，论文以这部作品为研究对象。下文用到的例子都来自这次过程，换成别的学位论文时，背后的原则同样适用。

## 一、选题的标准

1. **有限度的创新。**
   作者原话：“有创新是一定的，但是得有限度的创新……让老师看到既有已有的研究……又对比已有研究多了一点创新。”
   做法：选一个成熟的理论视角和研究角度，在新的题材或作品上推进一步，不标新立异。
2. **研究问题要具体，要有用。**
   - 好的问题，能给同类创作或研究提供可用的方法。作者举的参照是另一篇论文，那篇论文“好歹是给拍陌生人的创作提供帮助”。
   - 反例：围绕片中的“低谷”“落差”设子问题。作者批评：“太肤浅……你又是低谷又是落差，这完全是先射箭再画靶子。”
   - 也就是说，不能拿自己作品现成的特征，回头包装成研究问题。问题要来自创作或理论中真实存在的困难，作品是回答问题的案例。
3. **避开已经做烂的角度。**
   - “人物塑造这种研究实际已经做烂了”。
   - “视听等研究已经很多了，容易落入俗套”。
   - 作者仍然希望视听分析在文中占一席之地。处理办法是：把视听分析分散到各章，作为一节，或嵌进分析里写，不单独写一个空泛的视听章节。
4. **研究起点要稳。**不要依赖尚未定型的部分。例如成片还会调整，就以“谁为主、谁为辅”作为研究起点，作者认为这“有点给自己挖坑的嫌疑”。
5. **不要搞复杂。**“我不想搞的那么复杂”。一个理论，一个研究角度，一个清楚的题目范式就够了。
6. **理论要适配。**
   - 借用非本学科的理论（例如把哲学或社会学理论用到影像研究）之前，先问三件事：能否直接套用？与对象是否适配？有没有人这样写过？
   - 先辨析原概念的含义。例如布洛的“心理距离”指审美主体与对象之间的距离，不能拿来指拍摄者与被摄者之间的距离。
7. **定位要准。**
   - 作品的类型标签要与实际特征相符。片中访谈多，就不宜称“观察式纪录片”，按尼科尔斯的分类更接近“参与式”。
   - 题材的描述要准确：例如是“青年创业”，不是“青年返乡创业”。
8. **研究对象要与人物相关。**
   - 选择分析对象（例如片中的物）时，要看它与人物有没有情感上的牵连，能不能承载人物的经历。
   - 作者的取舍：“茶台平板等物件与主角没情感交互，没有多少研究意义”；摩托车和西装分别承载了悬念和经营起落，因此保留。

## 二、从现象到问题：选题的思考方式

1. **多列现象，再收束。**作者的要求：“发现的问题还是太片面……改为发现的现象，列举多一些……收束为一个高阶的理论追问，也根据这些思考改改研究问题。”
2. **把现象和问题合在一起写。**如果研究是“反着做”的，比如别人研究拍陌生人，自己研究拍熟人，就要“令人信服的讲清楚”自己这一面的具体困难，再由此引出实际问题。
3. **困难要写具体。**“访谈困难”“伦理模糊”太空泛，要落到片中的具体实例。
4. **不编造困境。**AI 曾虚构“不忍拍”“伦理影响剪辑”之类的创作心理，被作者评为“胡扯”。困难必须来自作者真实的经历和作品本身。
5. **作者给的例子是启发，不是答案。**
   - 作者原话：“我只是让你参考他这种说法”“我只是给你启发一下”。
   - 要把启发转成规范的学术表述，不要把原话直接写进题目或节题。
6. **辅助理论降级处理。**有适配度、但不宜作主线的理论，放进章节里的一节：
   - 拟剧理论的“台前与台后”，放进第四章的一节；
   - 物叙事，放在第五章；
   - 拍摄者与被摄者的关系，放进创作反思。
7. **给出可比较的方案。**选题阶段给两三个方案，每个写清题目、研究问题、主理论和章节如何递进，由作者挑选。作者有时会说“两个都写进汇报”。

## 三、选题汇报

作者向导师汇报时，要求“条理清晰”。经过几轮修改，汇报定为七个部分：

```
一、研究缘起与研究问题
   （一）研究缘起：把现象和问题合写，最后收束为一个核心问题
   （二）研究问题：一个核心问题，下分三个子问题，分别对应三个分析章
二、研究对象：作品的基本信息（时长、人物、拍摄周期）和类型定位
三、研究意义：理论意义与实践意义，各一段，不夸大
四、文献综述：与有影响力的研究对话；同类学位论文只作参考
五、理论基础：一个主理论，交代核心概念及其适用性；辅助理论说明用在哪一节
六、论文框架：章节目录，加一张递进关系图
七、研究方法与下一步工作；最后列出想请导师定夺的问题
```

几点要求：
- 引出问题时，不拿别人的研究作对比。
- 文献中待核的信息，标注“待知网核实”，并提醒作者去核。
- 题目一改，所有导出文件都要按新题目重新生成，并提醒作者旧文件已经作废。
- 格式要整洁。作者曾说“上次的太乱了”。具体要求见第七节。

## 四、题目的范式

学位论文题目的公式：

> ××（理论背景）视域下××（作品类型或题材）××（研究角度）研究——以毕业作品《××》为例

例子：
- 《空间叙事视域下青年创业题材纪录片的叙事结构研究——以毕业作品〈幕间〉为例》（定稿）
- 《手工艺题材纪录片的故事化叙事研究——以毕业作品〈种树椅〉为例》（作者给的参照）

要求：
- 研究角度用学界已有的说法，如叙事结构、故事化叙事、旁观与介入。不要自造，例如“熟人拍摄研究”“拍摄距离研究”“距离调适”。作者的评语：“很不专业”“这是一个学术概念？”“不够准确也不学术”“太玄了”“自造的概念不合规范”。
- 不把自己的问题直接摆进题目，也不用修饰性或意象化的说法（如“人近镜远”）。
- 研究角度不能太宽泛，读起来也不能拗口。例如“人物纪录片人物形象塑造”既“很拗口”，又“太宽泛”。
- 题目确定后，研究问题、框架、各章标题都要与它一致。
- 书名号嵌套用规范写法：《电视纪录片〈航拍中国〉的空间叙事研究》。

学位论文和期刊论文的题目不同：期刊论文可以用对举式、意象式的题目（见 `genre-templates.md` 第六节），学位论文以规范范式为准。

## 五、章节框架

### “理论+创作”型硕士论文的一般结构

这是作者暂定版的结构：

```
第一章 绪论
   1.1 研究背景与缘起  1.2 文献综述  1.3 研究意义  1.4 研究方法
第二章 理论章：××理论与××题材作品
   2.1 理论的核心概念（逐一界定，每个都对应后面的一章）
   2.2 该题材作品的创作概况
   2.3 该理论用于本类作品分析的适用性
第三、四、五章 作品分析，三章逐层递进，各三到四节
第六章 创作反思
   6.1 拍摄关系与进入方式  6.2 结构安排的得失（依据作者真实经历）
第七章 结论
```

### 三个分析章怎样递进

- 只用一个主理论，三章各取它的一个核心概念，由浅入深。例如：
  - 空间序列，是叙事结构的“骨架”；
  - 空间并置，是叙事结构中的“张力”；
  - 空间中的物，是叙事结构的“线索”。
- 反例：三种理论（空间叙事、拟剧理论、物叙事）各写一章。作者的评语：“这样好像并列了三个理论一样，没有逻辑顺承。”
- 三个章名用同一句式：“空间序列：《幕间》叙事结构的骨架”“空间并置：《幕间》叙事结构中的张力”“空间中的物：《幕间》叙事结构的线索”。
- 关键词要表意清楚，而且彼此对齐。“对照”一词，作者表示“不太理解”，改为“张力”之后，与“骨架”“线索”对齐。

### 节题的写法

- 句式对仗，用“X 与 Y：A 空间与 B 空间的 Z”：
  - 4.1 台前与台后：经营空间与私人空间的并置
  - 4.2 讲述与现场：访谈空间与事件空间的交替
  - 4.3 过去与现在：记忆空间与现实空间的叠合
- 反例：“过去与现在：重返旧直播间的口述”。作者的评语：“跟前面两节不对仗”“很口语化”。
- 同一章内，几节之间要有可以说出来的区别或递进。例如并置、交替、叠合，是三种不同的并置方式。
- 节题不加“（以……为例）”的括注。作者定稿时删掉了这类括注。

### 章内的安排

- 章节不能单薄，一章通常三到四节。作者说过：“第五章还得加上几个小节，否则太单薄”“第四章也略显单薄”。
- 作者采纳的写法，可以概括为“先总述，再个案，最后讲呈现”：
  - 5.1 物的复现：讲述中的物与画面中的物（总述：物在哪些段落出现、以什么方式出现）
  - 5.2 摩托车：跨越成功与困境的悬念线
  - 5.3 西装：经营起落的标尺
  - 5.4 物的视听呈现：景别、构图与声音
- AI 建议增加的节，作者不一定采纳。例如“4.4 声与画”就没有进入作者的定稿。建议宜少而精，定稿以作者的取舍为准。

## 六、分析作品与材料的规则

1. **以材料为准。**分析之前，先读作者提供的材料：转写稿、拍摄日志、场记表、剪辑版本记录。核对人物、数量、场次、情节，例如：
   - 有两位合伙人；
   - 卖的是摩托车，不是汽车；
   - 平板里的影像是实习时的直播，不是创业旧址的影像。
2. **只取客观的部分。**作者说：“只需你读取客观呈现本片内容的部分，一些主观上的指示不用管。”
3. **不编造情节。**AI 曾经写出片中并不存在的段落，作者说：“我并没有安排这样的情节”。写错了，就简短道歉，按材料改正，再给出符合实情的写法。
4. **每个分析都有依据。**标出场次编号、时间码或台词转写，例如“C03 茶台访谈”“C04 重返旧址”。
5. **写物是为了写人。**选择分析对象时，看它与人物的情感和经历有没有牵连。
6. **创作反思只写真实经历。**进入方式、具体日期、机位、剪辑的历史版本等，材料里没有的，标【待补】，请作者补充，不替作者编。
7. **类型和手法用学界已有的术语**，如参与式、声画对位、交叉剪辑。如果用到经典作品作参照（如朗兹曼的《浩劫》），只用来对照手法，不喧宾夺主。

## 七、篇幅、注释、格式与写作节奏

- **篇幅**：按学校要求或作者给的数字（如正文三万五千字）。先把字数分到各章各节。
- **注释**：按作者或学校的选择，如页下脚注（①②）加文末参考文献。全文统一。
- **写作节奏**：
  - 先拟定写作顺序和字数分配，请作者确认；
  - 然后一章一章写，每章确认后再写下一章。
  - 作者说过：“全文需在三万字以上，不宜整章写完，我认为应该先拟定好写作顺序框架，一章一章的来写。”
- **写作形式**：可以先写在便于批注的在线文档里，定稿后再排成 Word。
- **格式**（作者认可的排版）：
  - 正文：宋体小四，1.5 倍行距，首行缩进两字；
  - 标题：黑体，分级为“一、”“（一）”，或“第一章”“1.1”；
  - 列表：一律改为“（1）（2）”编号的段落，不用圆点；
  - 表格：三线表，加表题“表 1”；
  - 图：黑白灰配色，加图题“图 1”；
  - 页码：页脚居中；
  - 首页：标题区，“汇报人”“指导教师”处留空，由作者自己填写；
  - 正文中不留网页链接。

## 八、这次选题过程的走向

题目怎样一步步定下来，可以帮助校准作者的判断标准：

| 阶段 | 方案 | 结果 |
|---|---|---|
| 1 | 以“熟人拍摄”为核心 | 被否：不是学术概念 |
| 2 | 以布洛的“心理距离”讨论拍摄距离 | 被否：理论误用 |
| 3 | 以“距离调适”为题 | 被否：自造概念 |
| 4 | 把“人物形象塑造”作为研究角度 | 被否：拗口、宽泛、已经做烂 |
| 5 | 参照“旁观与介入”的说法 | 作者只是让参考它的说法，“距离”研究“太玄了”，可以降为一章来讨论 |
| 6 | 空间叙事、拟剧理论、认知电影、叙事认同，四个候选 | 选定空间叙事，拟剧理论降为小节 |
| 7 | 三个理论各成一章 | 被否：没有逻辑顺承 |
| 8 | 一个理论，三章递进（骨架—张力—线索） | 采纳 |

这个过程反映出作者的标准：
- 概念规范，优先于新奇；
- 理论适配，优先于理论数量；
- 结构递进，优先于面面俱到；
- 题目、问题、框架三者要互相对应。
