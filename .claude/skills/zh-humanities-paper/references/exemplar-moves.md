# 范文的写法拆解

作者提供了五篇范文，用来学习论证和行文的方法。这份文件拆解它们的骨架和惯用动作，供起草和评审时对照。

使用时注意两点：
- 学的是结构和手法，**不复制原文句子**。下文引用的原文片段都很短，只作说明。
- 范文与作者明确的要求冲突时，以作者的要求为准，见第三节。

## 一、五篇范文的骨架

### 1. 《分化与交叠：移动时代的时间》（理论思辨，约 1 万字）

- **题目**：两个对举的名词，加冒号和对象。张力本身就是全文的论点。
- **前言**：只有一段。
  - 从“变化”写起，第一句是“互联网不仅使得……也……，移动互联网应用更是加剧了这些变化”；
  - 接着给出论点：统一的时间轴被打破，人们在多种时间坐标的交叠中感知多重时间；
  - 末句预告三个方面：策略、行为与记忆。
- **正文**：四节，每节一组张力。
  - 一、公共性“媒体时间”与私人化“媒介时间”的分化；
  - 二、实时与延时的交错；
  - 三、“多线程”行为的交织；
  - 四、当下与永恒的纠结。
- **可学的地方**：
  - **开篇先划定概念范围。**先说明“媒介时间”尚无共识，再说明本文讨论的是哪两个方面，并说明“这与以往的研究有相关性，但并不完全一致”。接着区分“媒介”与“媒体”，理由是“为了便于区分”。
  - **给经典概念补上一个被忽视的维度。**以往研究看“拟态环境”，主要看内容的选择与呈现；本文指出，媒体建构的时间也是拟态环境的一个基本维度。
  - **用“点”与“线”刻画历史阶段。**论坛时代，个人只在公共时间轴上留下零散的“时间点”；博客之后，个人才有了自己的“时间线”。
  - **翻转式判断。**公共媒体时间受到冲击，并不意味着它应该消失；恰恰因为个人越来越分散，保留作为公共纽带的媒体时间才更重要。
  - **调和表面矛盾。**“网络是有记忆的”与“网络是没有记忆的”，“在不同的情境下……可能都是成立的”：前者指数据记录，后者指人脑与心理。
  - **借来的研究，先限定再取启发。**例如：“虽然现在还不能判断这一研究结果是否适用于多数用户，但其研究的启发是……”
- **结尾**：先用“综上所述”收束，再提出“值得进一步关注的是”：时间背后是权利或权力。最后两面落笔：“既可能……也有可能……”。

### 2. 《连接与反连接：互联网法则的摇摆》（理论思辨）

- **题目**：一个概念和它的反面，加冒号，再加一个动态意象（摇摆）。
- **前言**：四个短段。
  1. 连接是互联网的法则；
  2. 人与人的连接是核心，理解它可以“反观技术对人作用的深层机制”；
  3. “另一方面，我们也应该看到”，连接超过一定限度会走向反面；
  4. 提出命题：反连接“可能成为”另一种法则。
- **正文**：三节。演变与摇摆 → 过度连接下的重负 → 反连接的情境与实现路径。
- **可学的地方**：
  - **平行命名的类型学。**七种连接模式，名称都由“纽带或中心 + 互动形态”构成，如“以内容为纽带的群体互动”“以社交为核心的一对一互动”。每种都写到代表产品、它满足了什么、代价是什么。
  - **三组摇摆，写法相同。**远与近、匿名与实名、弱关系与强关系。每组都写早期状态、后来的变化、背后的需求，最后落到“需要在两者之间寻求平衡”。
  - **用一句话完成转折。**第一节末写个体在连接中寄托的三种诉求，随即以“获得也是以投入、隐忍、交换等为代价的”接入第二节的“重负”。
  - **先说概念不是什么。**“反连接并不是无条件切断所有连接、封闭个体，而是在一定的情境下……”，先排除误读，再加上限定条件（情境性）。
  - **组合式界定。**“圈层化”既包括“圈子化”，也包括“层级化”，两部分各有文献支撑；“层”又分为社会阶层与网络话语阶层。
  - **同一个词领起各小节。**五个小节都以“反连接”开头：一种情境性选择、对用户的新赋权、网络服务商权力的限制、一种反向产品思维、一种新的网络素养。
  - **每条建议都附代价。**例如：“正如……被遗忘权所引发的争论一样……如何实现公共利益与个人利益的平衡，仍然是一个需要不断权衡的问题。”
- **结尾**：承认“反连接并不是惟一或终极的答案”，回到钟摆意象，最后落到“为人的自由、均衡发展提供更好的铺垫”。

### 3. 《网络化身体：病毒与补丁》（概念建构加经验材料）

- **开篇**：
  - 先列一组带年份的案例：电影《搜索》、铜须门、虐猫、华南虎；
  - 再指出“人肉”这个说法本身的特别之处：它用机器的逻辑描述人的行为；
  - 接着把现象铺开：人肉评论、代购、快递、数据标注等。
- **反常与提问**：
  - 互联网兴起时，人们期待离身交流，期待机器取代人工；现实却相反，身体在成为网络的一部分。
  - 由此把麦克卢汉的论断翻转为“人是媒介的延伸”。
  - 然后分三层提问：为什么仍有这种“倒退”→ 身体如何被连接 → 身体与网络技术之间是什么关系。
- **概念工作**（全文最见功力的部分）：
  - **先清理混乱。**指出传播研究中的“身体”概念各不相同，“导致混乱”。
  - **再分路径。**两条传统路径（身体作为符号；身体作为文化与权力的场所），各用一句话说明忽略了什么；三个新问题（感官、隐喻、物质基础设施）。
  - **然后定位。**“本文主要是在第三个……维度上使用身体概念”。
  - **借日常语言撑起概念。**用日常说法“人肉”来突出身体的物质维度。
  - **一句话定义，括号内辨析。**定义“网络化身体”，再在括号里说明它与 Hine、Farman 的相近概念有何不同。
  - **不陷入术语之争。**对“网络”与“系统”之辨，说明“本文无意进一步加深……之辨……重点在于……”。
- **两个意象的处理**：
  - 交代意象的来源与视角：两个词来自计算机安全领域，是从系统而非人的视角作出的建构；
  - 声明意象不穷尽对象：两种类型不能概括全部，在具体个体身上还可能重叠；
  - 说明借用与原义的差别：“本文的‘补丁’概念与其原始意义并不完全一致，这个隐喻借用了……的意象，强调……”。
- **材料交代**：
  - 说明两份田野材料的来源、时间与方法；
  - 声明原研究的问题与本文不同，“本文的结论独立于上述两个研究的结论”。
- **在用到时点明差别**：讨论“断开连接”时，用一段话说明与相近研究（彭兰，2019）的不同。那篇讨论的是人与人社会关系层面的反连接，本文讨论的是物质和技术层面的断开。语气中性，不评高下。
- **讨论**：以“首先、其次、最后”提出概念带来的三点启发，每点都与一位理论家对话。最有力的一点是语法上的区分：“网络化的”（networked）不同于静态的“网络”（network），由此与卡斯特拉开距离。

### 4. 《智能机器的多重媒介意涵及其影响》（理论思辨）

- **开篇**：两三段，交代三件事：
  - **为什么选这个说法**：“为了将人工智能这一抽象概念具象化，本文主要采用‘智能机器’这一说法，但这并不只是指机器硬件”；
  - **它包含什么**：算力、算法、数据；
  - **不同意涵下起作用的要素不同**：有时是算法，有时是硬件，有时是整体。
- **正文**：四种角色，排列的依据是由浅入深。
  - 连接中的行动者（关系）；
  - “机器媒体”（内容）；
  - “镜子”（自我认知）；
  - 生活的“形塑者”（生存的基础层面）。
- **可学的地方**：
  - **一个功能拆成四步写。**算法媒介有四种作用：关系建构、调控与规训、转义、文化传承。每种都写到它是什么、怎样起作用、带来什么后果、用户还有没有主动权。
  - **与以往媒介对比。**“以往的媒介是由用户进行选择的……但算法这一媒介的选择权却不在用户手里”。
  - **看反面。**“算法的连接机制，在另一个角度看，也是隔绝机制。”
  - **梳理谱系。**内容生产主体经历了两次拓展：机构 → 个人（UGC），人 → 机器（MGC）。
  - **把质疑转回自身。**质疑机器有没有创造性时，反问人类自身的创造性是否足够。
  - **借理论家铺出层次。**米德、拉康、韩炳哲用来写“镜子”，彼得斯用来写“基础设施”；每位都是先说观点，再落到具体设备，如可穿戴设备、智能家电。
  - **点出开放问题。**例如：“这些系统中的信息未来是否会汇入现有的公共传播系统中……这些都是未来值得进一步研究的问题。”
- **结尾**：落到一个核心关切，以问句收束：智能机器是为人的自由发展提供更多可能，还是带来更多枷锁？

### 5. 《远程办公与智能工作平台中的时间政治》（质性经验研究）

- **研究缘起**：
  - 先写现象：疫情带来大规模远程办公；
  - 再写反常：越来越多的人反而想回办公室；
  - 由此推进：工作空间的改变，更深一层是时间控制的问题；
  - 最后指出视角的不足：只看时间“体验”（加速或减速）不够，要看时间的“存在”结构。
- **文献回顾**：两节，都用“从 A 到 B”作标题，如“从分布式公司到数字游牧民”“从钟表时间到拓扑时间”。
  - 每节梳理一个概念的演进，节点都带年份；
  - 节末用一句话总括，例如：“远程办公的概念演进经历了由工作地点到通讯技术，再到媒介化和平台化趋势的转变”。
- **理论概念**：
  - 沿思想史引出“拓扑时间”：海德格尔 → 塞尔（用手帕的褶皱作比喻，时间像“筛”）→ 许煜（补上“关系”和“事件”）；
  - 然后给出定义：“有鉴于此，本文将拓扑时间定义为……”；
  - 再说明它为什么适合这个对象：空间有时由时间决定，航海钟就是例子。
- **研究问题**：两个，编号，具体。
- **方法**：交代抽样方式、时间段、样本量、受访者信息表，以及研究者自己的参与式观察和身份位置。
- **发现**：
  - 第四节的总标题是意象加冒号；下设三个小节，各对应一个层面：结构、系统、规则。
  - 每个小节按同一个顺序写：
    1. 命题句；
    2. 肯定的一面（个体获得了自由、主体性），附访谈引语；
    3. 用“但……”复杂化，给出另一面的引语和数据；
    4. 理论阐释（韩炳哲、德勒兹）；
    5. 再推进一层，例如“拓扑时间……开始向内膨胀”。
- **抵抗与限度**：
  - 先写个体的三种策略：时间转移、时间欺骗、断连实践；
  - 再反思这些策略：“事实上，时间工作不仅是一种私人策略……个体……努力谈判的效果往往十分有限”。
- **结论**：理论贡献 → 发现回顾 → 结构性批判 → 制度路径（法国、西班牙的“断连权”立法，以及平台设计标准）。
- **访谈引语的用法**：
  - 短而鲜活，带编号，嵌进句子里。例如：“所谓的云办公，就是 24 小时 on call”（S9）。
  - 引语用来佐证命题，不代替命题。

## 二、论证动作库

下面的动作从五篇范文和作者认可的改稿中归纳而来，可以组合使用。每个动作附一个句式骨架，其中的 X、Y、A、B 由具体内容替换。

### 1. 从反常开篇
- **骨架**：具体现象（案例、年份、场景）→ 它与通常预期相反 → 由此提出问题，从具体到一般分层提出。
- **作用**：问题意识来自反常，而不是来自“研究很少”。
- **注意**：案例要真实可查，年份要准。

### 2. 划定用词与范围
- **骨架**：“X 并非一个有共识的概念……本文所讨论的 X，主要涉及……两个方面。这与以往的研究有相关性，但并不完全一致。”
- **骨架**：“为了……，本文主要采用‘X’这一说法，但这并不只是指……”
- **作用**：先说清本文在什么意义上用这个词，后文才不会被误读。

### 3. 拆词与辨析
- **骨架**：“X 在这里至少有三种含义：……、……、……。这几者有时同时发生，有时则是分离的。”
- **骨架**：“A 与 B 这两个概念往往被混用，但……侧重于……，而……更多指向……”
- **作用**：消除歧义；常常还能顺带化解表面矛盾。

### 4. 梳理路径，给本文定位
- **骨架**：“关于 X 的研究大致有 N 条路径。一是……，它关注……，但较少涉及……；二是……。本文主要在第 N 条路径上……”
- **注意**：评价每条路径时用中性的“较少涉及”，不用“忽视”“无视”。

### 5. 类型学
- **骨架**：给每一类起平行的名称，每一类按同样的顺序写：定义一句、典型例子、作用或代价。
- **注意**：类型数量与正文结构对得上；类型之间互斥，不能重叠。如果重叠，要说明“在具体个体身上还可能重叠”。

### 6. 用张力组织
- **骨架**：一组对举概念，每一端都写成立的理由，最后落到“摇摆”“交叠”“往复”“并存”，不简单站一边。
- **作用**：张力本身就是论点，也是章节骨架。

### 7. 引入理论家：观点—适用—限度
- **骨架**：“按照 X 的看法，……（出处）。虽然本对象……还做不到……，但……也会……”
- **注意**：
  - 理论家出场之前，上文要已经提出需要这个理论来回答的问题；
  - 转述要经得起回原文核对。

### 8. 给经典概念补上维度
- **骨架**：“以往的研究者关注到了 X，但更多地关注的是其 A 方面；事实上，B 也是 X 的一个基本维度。”
- **作用**：用最省力的方式在经典理论上推进，又不显得自我拔高。

### 9. 编织经验材料
- **骨架**：命题句 → 机制解释 → 访谈引语或数据（带编号或出处）→ 理论阐释 → 推进一层。
- **注意**：引语短，嵌进句子；一个命题配一两条最有力的材料，不罗列。

### 10. 先肯定，再复杂化
- **骨架**：“……在一定程度上实现了……。但……并非都是……，……”
- **作用**：避免一边倒，判断也因此更可信。

### 11. 与以往媒介或阶段对比
- **骨架**：“以往的……是……，……；而……则……。”
- **注意**：用“不只是……也是……”，少用“不再……而是……”。

### 12. 看反面
- **骨架**：“X 的……机制，在另一个角度看，也是……机制。”

### 13. 自我限定，提出开放问题
- **骨架**：
  - “当然，这里主要分析的是……，这并不意味着……”
  - “要对此做出明确判断，还有待……”
  - “……是否……，又将如何……，这些都是未来值得进一步研究的问题。”

### 14. 在用到时点明差别
- **骨架**：“国内研究亦曾借……概念讨论……（出处）。”或者：“某某（年份）也讨论过……，不过是在……层面；本文讨论的是……层面。”
- **注意**：只交代维度上的差别，不评高下，不另起一个“本文的创新”段落。作者更偏好前一种更含蓄的写法。

### 15. 回头审视个体的策略
- **骨架**：“事实上，……不仅是……，也是……的结果。……的效果往往十分有限，……”
- **作用**：经验研究不止于描述个体的策略，还要追问结构性的限度。

### 16. 结尾落到价值追问
- **骨架**：“综上，……。值得进一步关注的是，……的背后是……（权利、权力、自由）。它既可能……，也有可能……”
- **注意**：
  - 承认答案不是唯一的；
  - 理论对话集中在讨论或余论，不在各节末尾点名；
  - 不用煽情的省略号收尾。

## 三、不要照搬的地方

范文有几处与作者明确提出的要求不一致，写作时按作者的要求处理：

| 范文的写法 | 作者的要求 | 处理 |
|---|---|---|
| “讽刺的是”“反讽的是” | 不用修辞性反讽 | 删去，直接陈述 |
| “必将”“必然会”“完全可以”“杜绝了……的可能”“永生不死” | 不用全称判断、绝对副词 | 改为“往往”“容易”“难以”“可能” |
| 密集的理论修辞，如“拓扑式的时间暴力”“全权数字基础设施”“电子围捕” | 不用比喻代替判断，一句一意 | 意象可以用来命名和组织，但每个意象都要在正文中兑现为机制陈述 |
| 结尾用省略号和电影意象制造悬念（如“……正在向人类社会迫近……”） | 克制 | 用一个明确的价值追问收尾 |
| “并非……而是……”用得较多 | 慎用断裂式叙述 | 多用“不只是……也是……” |
| 单列一段说明与相近研究的不同 | 差别靠论证显现 | 压缩为一两句，或只用“国内研究亦曾……”带过 |

## 四、范文语言的共同特征

- **平实**：常用词多，生僻术语少；必要的术语加引号并当场解释，例如“同温层”的来历放在注释里。
- **句子中等长度**：主干清楚，少用多重定语。
- **例子是当下的、具体的**：倍速播放、弹幕、朋友圈分组、“已读”、健康码、企业微信的加急电话、外卖骑手的手机支架。
- **数字和年份精确**：通关人数、订单配送时长的变化、某一年的法律。
- **限定词适量**：“在一定程度上”“往往”“未必”用得自然，但一句话里不叠加。
- **元话语少**：小标题本身就是路标，正文很少说“下文将……”。
- **意象成体系**：钟摆、镜子、补丁与病毒、褶皱。一篇文章只用一组意象，并贯穿到底。
